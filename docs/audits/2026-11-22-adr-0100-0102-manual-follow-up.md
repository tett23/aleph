# [ADR 0100](../adr/0100-move-tree-files-and-folders.md) と [ADR 0102](../adr/0102-stable-editor-geometry-for-selection-highlights.md) の手動確認の続き

## 対象と方法

2026-11-22 に、コミット `006c66ce4a871991073934a4393ebb5129d8f381` の Tauri デバッグ版を macOS で操作した。
対象は [ADR 0100](../adr/0100-move-tree-files-and-folders.md) と [ADR 0102](../adr/0102-stable-editor-geometry-for-selection-highlights.md) の残っている手動確認である。
操作には CUA のマウスドラッグとキー入力を使い、選択内容をアクセシビリティ情報で、配置と一致の枠を画面で確認した。
これは画面操作の確認記録であり、セキュリティ監査や性能測定ではない。

試験用のアプリ識別子は `dev.tett23.aleph.adr-validation` とした。
通常の prod 版の原稿は操作していない。
デバッグ版は `npx tauri dev --config /tmp/aleph-adr-validation-config.json` でビルドし、ビルドは終了コード 0 で成功した。
試験後はアプリと開発サーバーを終了した。

## [ADR 0102](../adr/0102-stable-editor-geometry-for-selection-highlights.md) の確認結果

次の表は、今回実際に選択内容と画面を確認できた範囲である。
キーの反復は、選択を解除してから同じ文字列を選び直す操作を各ケースで 5 回行った。
横書きは Right と Shift+Left、縦書きは Down と Shift+Up を使った。
マウス操作は各ケースで一致文字列をドラッグ選択した。

| シートと表示 | 選択文字列 | 結果 |
| --- | --- | --- |
| 短い Markdown、ライト、横書き | `wrold` | URL 内の同じ文字列に枠が付き、本文の幅や位置に目視のずれなし |
| 短い Markdown、ライト、縦書き | `wrold` | 縦方向の文字列に枠が付き、反復後も文字位置に目視のずれなし |
| 長い Markdown の 283 行目、ライト、横書き | `本文` | 周辺の行に枠が付き、反復前後で表示行と文字位置を保持 |
| 同じ長文の途中、ライト、縦書き | `本文` | 縦横切り替え後の位置に枠が追従し、反復で追加の移動なし |
| 同じ長文の途中、ダーク、縦書きと横書き | `本文` | 両方向で枠を確認し、それぞれの選択反復で目視のずれなし |
| Golem の 2 シートの連続表示、ダーク、横書きと縦書き | `移動` | 1 枚目の別の一致に枠が付き、2 枚目を含む配置に目視のずれなし |

短いシートは `/tmp/aleph-ui-fixtures/00-sample.md`、長文は同じディレクトリの `selection.md` を使った。
複数シートは `/tmp/aleph-0100-fixture.77cJs2/B/group/one.gm` と `two.gm` を Cmd+クリックして連続表示した。
短いシートでは、診断の下線と一致の枠を区別できた。

今回の確認では、元の報告の幅のがたつきを再現していない。
画面の観察は、1/64 CSS px の矩形比較の代わりにはならない。
今回、100 回の反復計測や DOM の同一性の再計測はしていない。

ライトの複数シートの確認中には、選択した `移動` が `ん` に置き換わった状態を検出した。
この変化を発生させた入力は特定できていない。
Undo 後の本文が操作前と同じであることをアクセシビリティ情報で確認して保存した。
この試行を、ハイライトだけが変化するケースの成功にも、IME 変換の成功にも数えない。

残る範囲は、短文のダーク、複数シートのライト、各条件でのマウス選択の反復、検索結果と診断と一致の印の比較、日本語の変換中と確定後である。
一部の表示条件を確認できたが、A1〜A3 全体の完了とはしない。

## [ADR 0100](../adr/0100-move-tree-files-and-folders.md) の未確認項目

ドラッグ途中の移動先と不可表示、Esc による取消は未確認である。
今回使える CUA のドラッグ API は始点から終点までを一操作として実行する。
押下を保ったまま停止して画面を観察し、Esc を送る操作は提供されていない。

Finder からツリーへのコピーと、ツリーから Finder への受け渡しも未確認である。
`/tmp/aleph-native-drag-in/native-copy.md` を用意し、Finder でその一覧を表示するところまで進めた。
両アプリ間のドロップを完了できていないため、コピーと元ファイル保持を検証済みとはしない。

内部移動用に設定した検証用 Golem は `/tmp/golem-0399-488cb752a` である。
今回このバイナリで新たな内部移動の成功確認は行っていない。
試験後に、この指定を空欄へ戻した。

指示者から、ドラッグ中にシートの表示が動かない点の改善を求められた。
既存の [ADR 0100](../adr/0100-move-tree-files-and-folders.md) は移動先の印を定めるが、ドラッグ元の追従表示は定めない。
名前とアイコンの半透明なコピーを、シートとフォルダ共通で追従表示する案を、別の ADR として作成する。
