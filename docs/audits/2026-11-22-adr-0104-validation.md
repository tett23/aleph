# 変更の印と差分のタブの検証

対象は [ADR 0104](../adr/0104-preview-gutter-diff-and-open-diff-tab.md) である。
ワークスペースをリポジトリの直下と下位フォルダに置いたときの比較元、エディタ上のホバー、そこから開く差分のタブを確かめた。

## 自動テスト

- `npm run build` と `npm test` が成功し、Node の 1,013 件が通過した。`cargo test --manifest-path src-tauri/Cargo.toml --lib` は 212 件が通過し、6 件がテスト定義どおり除外された。
- `node --test app/gutter-diff.test.ts` で、マーカーの変更範囲、末尾と全体の削除、同じ行の複数の変更、比較の上限、日本語と補助平面の文字の復元、差分の 2,000 表示行制限、非同期の結果の破棄を確かめた。
- `scripts/check-diff-hover-webkit.sh` で、macOS の WKWebView で 33 項目を確かめた。制御した時計で 299 ミリ秒ではホバーが出ず、300 ミリ秒で出た。倍率を 100%、200%、400% に変え、可視領域のサイズとオフセットを変えた前後の描画フレームで外枠を測った。AppKit から送ったホイールイベントで変更前と変更後の末尾に達し、境界でエディタがスクロールしないことを確かめた。
- 同じ WKWebView のテストで、行の矩形と選択を測った。診断には診断のホバーが出て、差分マーカーには変更のホバーが出た。未保存の本文を差分のタブに渡して、再読み込みの遅い結果が新しい表示を上書きしないことを確かめた。

- Rust の `adr0104_i1_head_text_has_the_same_meaning_from_the_root_and_a_subdirectory` で、同じ HEAD の本文をリポジトリの直下と下位フォルダの両方から取得した。リポジトリ外、コミットなし、HEAD に対象なし、UTF-8 で読めない場合の戻り値も確かめた。

## Tauri での確認

本番版と別の識別子を持つ検証版を使った。
Git リポジトリの下位フォルダをワークスペースにし、二つの Markdown ファイルに、約 260 行が続く長い変更をそれぞれ用意した。
自動コミットを無効にし、自動保存の間隔を 600 秒にした。

- 横書きのライトテーマで 3 行目の印を押し、該当箇所を差分のタブに表示した。本文に「未保存の追記。」を入力した後、未保存の印がある状態で同じ変更の印を押した。同じ差分のタブに「未保存の追記。」が追加として出た。「ワークスペース全体の差分」を押し、保存済みの変更がある二つのファイルの一覧に戻った。
- 3 行目の印にポインターを重ね、変更前と変更後に日本語の変更箇所が出た。その状態で 11 秒以上静止しても表示が残り、下線のある「詳細」から同じ差分のタブを開けた。
- 5 行目の長い変更では、最大幅と最大高さに達してもホバーは画面内に収まった。変更前と変更後を個別にスクロールし、「変更前の末尾。」と「変更後の末尾。」を読めた。スクロール中も見出しと「詳細」は表示され、背後の本文の位置は変わらなかった。Esc でホバーが閉じた。

## 手で確かめる残りの項目

縦書きとダークテーマ、ウィンドウの上下左右の端、診断の印との操作の違いは WKWebView で自動確認した。
Tauri ではこれらの条件を実際のマウスで確認する作業が残る。
Tauri でホバーの本文内にポインターを置いたまま 10 秒静止し、両方の領域から離れると閉じることを確かめる。
変更前と変更後の末尾でホイールを回し、背後の本文が動かないことも確かめる。
別の印でも同じ差分のタブを再利用し、未保存の差分を開いた直後にディスクの内容が変わっていないことを照合する。
