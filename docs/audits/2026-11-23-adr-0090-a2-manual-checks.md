# [ADR 0090](../adr/0090-editor-composition-settings.md) A2 の手の確かめ (2026-11-23)

## 対象と環境

- 対象は [ADR 0090](../adr/0090-editor-composition-settings.md) の A2 (折り返し付近で選択、コピー、IME 入力、取り消しができ、ぶら下げた文字も選択できる) である。
- tett23/aleph#176 のブランチ (コミット `4b5f278`) から `npx tauri build` で作ったリリース版で確かめた。macOS は 27.0 である。
- Golem は、[A1 の記録](2026-11-23-adr-0090-manual-checks.md) と同じく、`kinsoku` のコマンドを持つ Golem の main からビルドしたものを、設定の `golemPath` に指定した。
- 確かめには、A1 と同じ使い捨てのプロジェクトを使った。`style.toml` は `kinsoku = "strict"`、`hanging-punctuation = true`、`[page.grid] characters = 10` で、書字の向きは横書きである。3 行目の「あいうえおかきくけこ。さしすせそ」は、「。」が 10 字目の「こ」の後ろで行の外にぶら下がり、「さしすせそ」が次の行に折り返された。
- 書き手の `config.json` と `window.json` は、確かめの前に控え、後で戻した。戻した後の二つのファイルの SHA-1 は、控えと同じだった。
- 操作は、指示者の許可を得て、画面を借りる操作 (クリック、ドラッグ、キー、クリップボードの読み取り) で行った。入力メソッドは、書き手の環境の SKK のかなの入力だった。

## 結果

- 選択：ぶら下げた「。」の後ろにカーソルを置き、⇧← を 2 回押すと、「こ。」が選択の色になった。ぶら下げた「。」も選択の色の中に入った。
- 選択：「こ」の前から、折り返した次の行の「し」の前までドラッグすると、折り返しをまたいで選択できた。
- コピー：⇧← で選んだ範囲を ⌘C でコピーすると、クリップボードの中身は「こ。」だった。ドラッグで選んだ範囲では「こ。さし」だった。
- 入力：ぶら下げた「。」の後ろにカーソルを置いて「テスト」を打つと、「。」の後ろ (折り返した次の行の頭) に入った。
- IME 入力：同じ位置で、SKK のかなの入力で a を押すと「あ」が入った。続けて ⇧K、a を押すと、変換中の「▽か」と候補の一覧がその位置に出た。Return で確定すると「か」が入った。
- 取り消し：⌘Z を押すたびに、入れた字が一つの入力ずつ消え、元の「あいうえおかきくけこ。」と「さしすせそ」の折り返しに戻った。行の変更の印も消えた。自動の保存の後のファイルは、確かめの前のファイルと同じだった。

## 残ったこと

- 縦書きでの A2 は、確かめていない。A2 は書字の向きを指定していない。
- 確かめの後、クリップボードには「こ。さし」が残った。確かめの前のクリップボードは、テキストとして空だった。
