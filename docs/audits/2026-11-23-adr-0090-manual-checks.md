# [ADR 0090](../adr/0090-editor-composition-settings.md) の手の確かめ (2026-11-23)

## 対象と環境

- 対象は [ADR 0090](../adr/0090-editor-composition-settings.md) の A1 (縦書きと横書きで、禁則とぶら下げの設定を切り替えると、境界表の表示になる) である。A2 (折り返し付近の選択、コピー、IME の入力、取り消し) は確かめていない。
- `loose` を `line-break: auto` に写すように直したブランチ (コミット `718bffc`) から、`npx tauri build --debug` で作ったデバッグ版で確かめた。
- Golem は、`kinsoku` のコマンドを持つ Golem の main (コミット `ff85e3705`) からビルドしたものを、設定の `golemPath` に指定した。
- 確かめには、使い捨てのワークスペースのプロジェクトを使った。`style.toml` の `[page.grid] characters` を 10 にし、章に次の行を置いた。どの行も、10 字目の「こ」の直後に、確かめる字が来る。
  - 「こ。」「こ、」「こ」」「け「こ」(開き括弧が 10 字目)「こっ」「こー」「こ？」「こ々」「こ〜」
- `style.toml` は、アプリで開いたまま、アプリの外で書き換えた。アプリは外での変更を読み込み、読み直した値を章のエディタに当てた。
- 書き手の `config.json` と `window.json` は、確かめの前に控え、後で戻した。戻した後の `config.json` の SHA-1 は、控えと同じだった。
- 操作は、画面を借りない背景の操作 (クリックと、ウィンドウごとの画面の取り込み) で行った。

## 結果

| `style.toml` | 書字の向き | 結果 |
| --- | --- | --- |
| `[composition]` なし (`strict`、ぶら下げない) | 横書き | 。、」は行頭に来ず、「こ」と一緒に次の行へ送られた。「 は行末に残らず次の行へ送られた。っ と ー も行頭に来なかった |
| `hanging-punctuation = true` | 横書き | 。と、が 10 字目の後ろで行の外にぶら下がった。」はぶら下げず、次の行へ送られた |
| `kinsoku = "loose"` | 横書きと縦書き | っ と ー が行頭に来た。？ 々 〜 は行頭に来ず、「こ」と一緒に次の行へ送られた。。、」と「 は `strict` と同じだった |
| `kinsoku = "strict"`、`hanging-punctuation = true` | 縦書き | 。と、が行の下にぶら下がった。」はぶら下げなかった。っ と ー は行頭に来なかった |
| `kinsoku = "medium"` (誤り) | 横書き | 通知に G03006 (kinsoku に使えない値) と `style.toml` の絶対パスが出た。エディタは、最後に読めた `loose` のまま折り返した |

- 設定を変えた後、再起動せずに、開いている章のエディタの折り返しが変わった。
- `style.toml` をアプリで開いていないあいだに外で書き換えても、エディタは読み直さなかった。読み直すのは、アプリで開いた `style.toml` を保存したときか、開いている `style.toml` が外での変更を読み込んだときである。

## ほかに気づいたこと

- `loose` を WebKit の `line-break: loose` に写していた前のコード (tett23/aleph#172) では、横書きで っ と ー が行頭に来た。Aleph の画面が `lang="ja"` なので、WebKit は日本語の規則を使う。`lang` の無い検査のページで測った前の調査は、これを見落としていた。測り直した結果は [エディタと同じ形の要素での禁則とぶら下げ](../research/2026-11-23-editor-kinsoku-probe.md) にある。
