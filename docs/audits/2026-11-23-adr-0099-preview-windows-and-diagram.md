# [ADR 0099](../adr/0099-explicit-light-and-dark-appearance.md) の別のウィンドウと図の手の確かめ (2026-11-23)

## 対象と環境

- 対象は [ADR 0099](../adr/0099-explicit-light-and-dark-appearance.md) の A1 の残り (本文とページのプレビューの別のウィンドウ) と A3 である。A1 のうちプロットの別のウィンドウと A2 は、[前の記録](2026-11-23-adr-0098-0099-manual-checks.md) で確かめた。
- [前の記録](2026-11-23-adr-0098-0099-manual-checks.md) と同じデバッグ版 (main のコミット `8f0080d` から `scripts/bundle-tools.sh` と `npx tauri build --debug` で作ったもの) で確かめた。macOS の外観はライトだった。
- 確かめには、使い捨てのワークスペースを使った。Git のリポジトリの中に、`manifest.toml`、`style.toml`、章を一つ持つ縦書きのプロジェクトと、Mermaid の図 (`diagram.mermaid`) を置いた。
- 書き手の `config.json` と `window.json` は、確かめの前に控え、後で戻した。戻した後の `config.json` の SHA-1 は、控えと同じだった。
- 操作は、画面を借りない背景の操作 (クリック、スクロール、ウィンドウごとの画面の取り込み) で行った。

## A1 の残り：本文とページの別のウィンドウ

- 本文：ライトでプレビューを本文のモードにし、見出しのボタンで別のウィンドウに出すと、明るく開いた。メインのウィンドウの設定で「ダーク」を選ぶと、別のウィンドウは一度白くなった後に暗く描き直された。「ライト」に戻すと、明るくなった。
- ページ：ダークのままページのモードで組み、見出しのボタンで別のウィンドウに出すと、ウィンドウの地とタイトルバーが暗く開いた。ページそのものは白い紙のまま描かれた。「ライト」を選ぶと地とタイトルバーが明るくなり、「ダーク」に戻すと暗くなった。
- OS がライトのまま、明示した「ダーク」が本文とページの別のウィンドウに伝わった。
- 一度だけ、ページの別のウィンドウが「ライト」を選んだ後に 15 秒ほど真っ白のままになった。ウィンドウの上でスクロールしても描かれず、次に「ダーク」を選ぶと描かれた。
- その後にもう一度「ライト」を選んだときは、すぐに明るく描かれ、白いままにはならなかった。白いままになる現象は、再現できなかった。
- 白いあいだも、タイトルバーは明るくなっていた。そのため、外観の値はウィンドウに伝わっていた。中身が白いことが [ADR 0099](../adr/0099-explicit-light-and-dark-appearance.md) の I1 (全ウィンドウが指定の外観になる) に反するかは、判断できない。
- 原因は調べていない。描き直しの遅れか、背景の操作での画面の取り込みが途中の画面を返したものと推測する。

## A3：Mermaid の図

A3 のうち、図の配色の描き直しを確かめた。スクロールの位置は確かめられなかった。

- 図のシート (`diagram.mermaid`) のプレビューは、ダークでは暗い箱と明るい字で、ライトでは Mermaid の明るい配色 (薄紫の箱と黒い字) で描かれた。外観を変えると、そのたびに図が新しい外観の配色で描き直された。
- Aleph が Mermaid の図を描くのは、図のシートのプレビューだけである (`app/preview/mount.ts` の `renderMermaid` の呼び出し)。Markdown や Golem の本文のプレビューは、図を描かない。
- 図のシートのプレビューは、図をプレビューの領域に収まる大きさに縮めて描く (`app/style.css` の `.media svg` に `max-width: 100%` と `max-height: 100%` がある)。
- 実際に、`diagram.mermaid` のノードを 41 個と 151 個に増やしても、図は縮んで領域に収まり、プレビューはスクロールしなかった。そのため、今の実装には、図を含むプレビューをスクロールできる画面が無い。

## ほかに気づいたこと

- 確かめに使ったプロジェクトは、初めは `metadata.id` と `metadata.date` が無く、ページのモードの組みが Golem の必須のキーの不足 (G03001) で失敗した。そのあいだ、ページのモードのプレビューは「更新できませんでした」と出し、本文を出した。二つを足すと組めた。
