# [ADR 0098](../adr/0098-ribbon-enabled-and-selected-states.md) と [ADR 0099](../adr/0099-explicit-light-and-dark-appearance.md) の手の確かめ (2026-11-23)

## 対象と環境

- 対象は [ADR 0098](../adr/0098-ribbon-enabled-and-selected-states.md) の A1、A2 と、[ADR 0099](../adr/0099-explicit-light-and-dark-appearance.md) の A1、A2 である。
- main のコミット `8f0080d` から、`scripts/bundle-tools.sh` と `npx tauri build --debug` で作ったデバッグ版で確かめた。macOS の外観はライトだった。
- 確かめには、使い捨てのワークスペース (Git のリポジトリの中に、`manifest.toml`、`style.toml`、章を一つ持つプロジェクトを置いたもの) を使った。
- 書き手の `config.json` と `window.json` は、確かめの前に控え、後で戻した。戻した後の `config.json` の SHA-1 は、控えと同じだった。
- 操作は、画面を借りない背景の操作 (クリックとアクセシビリティの読み取り) で行った。

## [ADR 0098](../adr/0098-ribbon-enabled-and-selected-states.md)

- リボンの項目は、名前を持つトグルのボタンとしてアクセシビリティから読めた (「ファイル」「差分」「プロット」など)。
- A1：ライトとダークのどちらでも、無効なプロットの項目だけが薄く描かれ、ほかの項目は通常の濃さで描かれた。選んでいる「ファイル」の項目には背景が付き、三つの状態を見分けられた。
- 無効なプロットの項目を押しても、何も起きなかった。
- A2：プロジェクトのシートを開いたまま、アプリの外で見出しの行だけの `plot.csv` を作ると、再起動なしでプロットの項目が使える濃さになり、ツリーに「プロット」の行が出た。押すとプロットが開き、項目に選択中の背景が付いた。`plot.csv` をアプリの外で消すと、項目は薄くなり、選択中の背景も外れた。
- 無効なプロットの項目のツールチップの文は、背景の操作ではポインターを乗せられないので、見ていない。

## [ADR 0099](../adr/0099-explicit-light-and-dark-appearance.md)

- 設定の「一般」の「外観」に「OS に合わせる」「ライト」「ダーク」があり、保存してある値の選択肢が選ばれた状態で出た。
- A1 (プロットの別のウィンドウ)：「ダーク」を選ぶと、メインのウィンドウが暗くなり、`config.json` の `theme` が `dark` になった。そのあとで開いたプロットの別のウィンドウも、暗く開いた。メインのウィンドウで「ライト」を選ぶと、開いているプロットの別のウィンドウも明るくなり、「ダーク」に戻すと暗くなった。OS がライトのまま、明示した「ダーク」が別のウィンドウに伝わった。
- A2：「ダーク」を選んだままアプリを終了して起動しなおすと、ダークのまま開いた。
- 本文とページのプレビューの別のウィンドウ (A1 の残り) と、Mermaid の図の描き直し (A3) は、確かめていない。

## ほかに気づいたこと

- プロットのタブを開いたまま `plot.csv` を消し、アプリの外で作り直すと、開いたままのタブは「0 シーン」のままだった。そのあとで開いた別のウィンドウは、作り直した行を読んだ。開いているプロットのタブが、外での作り直しを読み直さない可能性がある (原因は調べていない)。
- 拡張子の無い名前で新しいシートを作る確かめ ([ADR 0093](../adr/0093-ask-sheet-extension.md)) は、背景の操作では名前の欄に文字が入らず、できなかった。
