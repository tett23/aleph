## ループバック通信

`scripts/git-transport-fixtures/` の試験で、クライアントから実行ファイルを探せない PATH を使った。
SSH は未知の鍵と不一致の鍵を拒否し、既知ホストに登録した鍵で SSH エージェントによる push と pull が成功した。
HTTPS は信頼していない証明書を拒否した。
試験プロセスだけが試験用 CA を信頼する構成では、認証ありの push と pull が成功し、認証失敗、リモートによる拒否、non-fast-forward の拒否、マージと競合を検査した。
認証の取消は、資格情報を渡す再試行が起きないことを TypeScript のテストで確かめた。

## 設定を隔離した配布用 Tauri

別のリリースビルドを使い、Git に設定の探索先と SSH の既知ホストを一時ディレクトリから読むよう指定した。
アプリの Git 操作と画面には製品コードを使った。
アプリの PATH には、起動されたときだけ印を残す偽の Git を置いた。
macOS の実行制限で Git 本体の起動を拒否できることは別のプロセスで確かめた。
同じ制限を付けたアプリは画面操作で検証できなかったため、ここで記録するアプリの試験は PATH を隔離して行った。

SSH の検証用リポジトリでは、既知ホストの登録と SSH エージェントを使って pull した。
履歴に `9f91e80` が加わり、pull 後に章を開いてリモートの改稿を読んだ。
続けて Aleph で章を編集してコミットし、push した。
クライアントとサーバーで HEAD はどちらも `2e94f336178d8e6b9744053229f4b1be5b94509b` となり、サーバー側の章に追記が入っていた。


HTTPS の検証用リポジトリでは、アプリの試験プロセスだけが試験用 CA を信頼するようにした。
pull と push それぞれで認証フォームを開き、試験用ユーザー名とトークンで別々に認証した。
pull で履歴に `182f9f3` が加わり、章にリモートの改稿が表示された。
Aleph で追記してコミットしてから push した結果、クライアントとサーバーで HEAD はどちらも `443ef0592c42d74980bad7134606ef7ecb634220` となり、サーバー側の章に HTTPS の試験用の追記が入っていた。

SSH の検証用リポジトリでローカルの著者設定を消した後に手動コミットを試すと、不足している名前とメールアドレスを案内するモーダルが出た。
同じモーダルで「このリポジトリだけに設定」の下線と、ボタンのラベルの表示を確認した。
「グローバル設定を開く」を押すと、検証用の空のグローバル設定ファイルを保存先とするフォームが開いた。
両項目を保存すると有効値に反映され、設定を閉じて手動コミットを再実行すると `fc7087e` ができた。
試験用のグローバル設定ファイルは、実際の設定へアクセスしないよう起動前に空のファイルを置いていた。
設定ファイルが無いときの判定と保存時の作成は Rust の自動テストで確かめた。

検証用ワークスペースに未追跡の `auto-start-check.gm` を追加してアプリを再起動した。
新しいコミット `1274da7 Autosave 2026-11-22` にファイルが入り、設定の自動コミット成功日が `2026-11-22` になった。
この時点までの検査で、偽の Git の実行を示すファイルは作られなかった。

別の配布用 Tauri で、アシスタントの応答だけを試験用に固定し、適用は実際の WebView と製品の IPC を通した。
未追跡の `writer-draft.gm` がある状態で「コミットして適用」を選ぶと、`27193ab Before the assistant's edit 2026-11-22 23:46` ができた。
コミットには `writer-draft.gm` が入り、コミット中の章は「初稿」、作業ツリーの章は「アシスタントの改稿」になった。

次の検証用 Tauri では、同じリポジトリを開いて章の変更マーカーを確かめた。
差分のタブの描画処理を呼び出して、「アシスタント」を含む追加箇所が表示されることも確かめた。
検索パネルから置換を始めると、確認に「Git の変更から戻せます。」が表示された。
確認を閉じて置換を取り消した。
これらの操作は検証用 WebView のコードから行い、エディタ、Git 操作、差分、検索パネルのコードには製品のものを使った。

## 残る確認

検証用アプリの PATH には失敗する偽の Git だけを置いた。
Git 実行ファイル自体を OS で起動拒否した状態で、配布用 Tauri の一連の画面操作を確かめる作業が残っている。
