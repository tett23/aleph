# デザインの原則

この文書は、Aleph の画面を設計するときの原則をまとめる。
個々の動作は ADR で定め、実装済みの振る舞いは [仕様書](specifications.md) に記す。
ここに記した原則が、既存の画面すべてに反映済みであることは意味しない。

## クリックできるテキスト

テキストリンクには、常に下線を引く。
ホバーする前から操作できると分かるようにし、色やポインターの変化だけに依存させない。
リンクや「詳細」など、文字だけで示す操作に適用する。
枠や背景などでボタンと分かる操作には、ラベルの下線を付けない。
無効でクリックできないテキストは下線を付けず、無効であることを見た目とアクセシビリティ属性で示す。

下線は文字の範囲に付け、本文の折り返しや行の寸法を変えない。
下線のない通常の本文と、クリックできるテキストを明暗両テーマで見分けられるようにする。
