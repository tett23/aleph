# ロードマップ

まだ ADR にしていない、これから検討する機能を並べる。
検討を始めるときに ADR を書き、採択したらここから消して [仕様](specifications.md) と ADR に移す。
最後の「手で確かめる項目」には、実装と自動のテストは終わったが、ADR が求める手の確かめが残っている項目を並べる。確かめた結果をプルリクエストか `docs/audits/` に書いたら、項目を消す。

## 日本語の形態素解析による文章の検査

[ADR 0030](adr/0030-spelling-and-grammar.md) の文章の検査は、形態素の解析なしに文字の並びで判断できる規則に絞った。
形態素の解析があれば、次のような検査ができる。

- 二重助詞（「私は彼は」「の」の連続など）
- 文の係り受けの誤り
- 敬語の誤り
- 受け身の多用
- ら抜き言葉と表記ゆれの、決まった一覧によらない検出

決めることは、解析の仕組み（自前で書くか、辞書をどう持つか）、辞書の大きさと配り方、依存を増やさない方針との折り合いである。
メンテナーが、[ADR 0030](adr/0030-spelling-and-grammar.md) の下書きのレビューで、ロードマップに載せるよう求めた（2026-11-08）。

## ⌘R とメニューからの画面の再読み込み

開発とデバッグのために、⌘R と macOS のメニューの項目から、画面 (webview) を読み込みなおせるようにする。
今は、画面の不具合を確かめなおすたびに、アプリを終了して起動しなおしている。

決めることは、次のとおりである。

- メニューのどこに置くか (「表示」か、開発のときだけ出す「開発」のメニューか)。
- リリース版でも使えるようにするか、開発のときだけにするか。
- 保存していないシート、開いているタブ、別のウィンドウ (プレビュー、プロット) を、読み込みなおす前と後でどう扱うか。
- ⌘R と重なる、今のショートカットとキーの割り当て ([ADR 0073](adr/0073-contextual-editor-shortcuts.md)) との折り合い。

メンテナーが、デバッグのために求めた (2026-11-18)。

## 右クリックでネイティブのメニューを出さない

画面の中で右クリックしたときに、webview のネイティブのコンテキストメニュー (「再読み込み」「要素の詳細を表示」など) を出さないようにする。
コードを読んだかぎりでは、ツリー、タブ、キーワードのパネルなど、Aleph が自分のメニューを出す場所のほかでは、右クリックを止めていないので、ネイティブのメニューが出る (画面では確かめていない)。

決めることは、次のとおりである。

- エディタとテキストの入力欄で、コピーや貼り付けのメニューを残すか、Aleph のメニューを出すか。
- 開発のときに「要素の詳細を表示」を使えるようにするか。上の「⌘R とメニューからの画面の再読み込み」とあわせて決める。

メンテナーが求めた (2026-11-18)。

## 手で確かめる項目

- **アシスタントの手の確かめ（[ADR 0081](adr/0081-assistant-with-local-llm-and-connectors.md) A2、A4、A5）**：[ADR 0081](adr/0081-assistant-with-local-llm-and-connectors.md) の、ネットワークを切った Mac でダウンロードなしに答えが返ること（A2、A4）と、ログアウトした Claude Code でローカルに頼み直すこと（A5）を、`scripts/bundle-tools.sh` で同梱したデバッグ版で確かめる。同じ ADR の A3 と A6、[ADR 0088](adr/0088-diff-tab-and-commit-before-applying.md) の A1〜A4 は、2026-11-18 にデバッグ版で確かめ、結果をこの項目を短くしたプルリクエストに書いた。
- **承認の取り消し（[ADR 0089](adr/0089-revoke-connector-approval.md) A1）**：[ADR 0089](adr/0089-revoke-connector-approval.md) の、Claude Code を承認した後に設定で取り消すと行が「承認していません」になり、次に頼むと承認のダイアログがもう一度出ることを、デバッグ版で確かめる。
- **プレビュー更新後の位置（[ADR 0097](adr/0097-restore-preview-scroll-on-refresh.md) A1、A2）**：タブと別ウィンドウの本文とページを途中までスクロールして保存または組み直しを行う。横書き、縦書き、ズーム後、画像を含む本文で復元を確かめる。縦書きでは画面上の位置と WebKit の負の `scrollLeft` を記録する。
