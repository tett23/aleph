# ロードマップ

まだ ADR にしていない、これから検討する機能を並べる。
検討を始めるときに ADR を書き、採択したらここから消して [仕様](specifications.md) と ADR に移す。

## 日本語の形態素解析による文章の検査

[ADR 0030](adr/0030-spelling-and-grammar.md) の文章の検査は、形態素の解析なしに文字の並びで判断できる規則に絞った。
形態素の解析があれば、次のような検査ができる。

- 二重助詞（「私は彼は」「の」の連続など）
- 文の係り受けの誤り
- 敬語の誤り
- 受け身の多用
- ら抜き言葉と表記ゆれの、決まった一覧によらない検出

決めることは、解析の仕組み（自前で書くか、辞書をどう持つか）、辞書の大きさと配り方、依存を増やさない方針との折り合いである。
メンテナーが、[ADR 0030](adr/0030-spelling-and-grammar.md) の下書きのレビューで、ロードマップに載せるよう求めた（2026-11-08）。
