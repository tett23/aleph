# 日本語 20 万字でのローカル推論の試行

[ADR 0117](../adr/0117-expand-assistant-context.md) の全文での推論を、メンテナーの Mac で試した。
小説風の段落を繰り返して 20 万字にし、最終段落に確認語を置いた。
Golem のマニュアルから 8,000 字を加え、末尾の確認語を JSON の説明に出すよう頼んだ。
使ったモデルは同梱の Qwen3.5-4B Q4_K_M である。
`llama-server` を専用の UNIX ソケットで起動し、GPU オフロードを有効にした。
二つの設定に同じメッセージを送り、回答の上限は 128 トークンに揃えた。

| コンテキスト長 | 入力トークン | 結果 | 最大 RSS |
| ---: | ---: | --- | ---: |
| 4,096 | 142,788 | 上限超過で HTTP 400。応答に 0.12 秒 | 未計測 |
| 262,144 | 142,788 | 起動に成功。360 秒で回答が戻らず計測を終了 | 11,464,768 KiB |

262,144 では、開始から約 331 秒で 47,881 トークンを処理した記録が残った。
末尾の確認語の取得と長文での回答品質は確認できていない。
この試行は、既存の 4,096 トークンのベンチマークやその予算とは別に行った。
