# ADR 0007: 縦書きのエディタ

ステータス: 採択→[ADR 0019](0019-one-editor-for-both-writing-modes.md)

## 文脈

縦組みの本を書くとき、原稿も縦書きで書きたいことがある。
CodeMirror 6 は縦書き（`writing-mode: vertical-rl`）を扱えない。
行の高さ、カーソルの移動、選択、溝の配置が横書きを前提にしているためである。

プロトタイプでは、縦書きのときだけ `textarea` を `vertical-rl` にして編集した。
行番号は、`textarea` の裏に同じ字詰めの影の層を重ね、各行の上に出した（差分の印はさらにその上）。
影の層の文字は透明にし、行番号と印だけを見せた。
この方法は、影の層と `textarea` が同じ字の大きさと同じ折り返しになることに頼る。
そのため、命令を等幅にするといった、字の大きさが混ざる色付けはできない。

## 実装すること

- 縦書きのエディタは、`textarea`（`writing-mode: vertical-rl`）と、その裏に重ねた影の層で作る。影の層は `textarea` と同じフォント、文字サイズ、行間、余白、折り返しの規則（`white-space: pre-wrap`）を持つ。
- 影の層には、原稿の各行を一つのブロックとして置き、各行の上（行の頭）に行番号を、その上に HEAD からの変更の印を出す。折り返した行では、1 列目の上にだけ番号を出す。
- 列の高さは、字詰め（[ADR 0006](0006-horizontal-editor.md)）の字数に合わせる。
- `textarea` は中でスクロールさせず、文字の量に合わせて横に伸ばす。外側の枠を右端を起点にスクロールさせる（右から読み始める）。開いたときは原稿の冒頭を表示する。
- 縦と横はツールバーで切り替える。切り替えても、文書と保存の状態は変えない。
- 自動保存は横書きと同じに扱う（[ADR 0011](0011-saving-and-git.md)）。

## 実装しないこと

- 縦書きでの色付けと、命令と式の等幅。影の層と字の大きさがずれるためである。
- 縦書きのエディタの中での LSP の表示（波線、溝の印、ホバー、補完）と整形。縦書きでもサーバーとの同期は続け、診断はステータスバーの数と左のサイドバーの診断のパネル（[ADR 0015](0015-diagnostics-and-search.md)）で見る（[ADR 0009](0009-lsp-and-formatting.md)）。⌘S は整形せずに保存する。
- 複数の章をまとめて開いたときの縦書き（[ADR 0006](0006-horizontal-editor.md)）。
- 縦中横などの組版上の表現を、エディタの中で見せること。組んだ姿はプレビュー（[ADR 0010](0010-previews.md)）で見る。

## テスト設計

- 影の層の行の組み立て（行番号、変更の印、空行の扱い）は、原稿と変更の印から HTML を作る関数として `node --test` で確かめる。
- 画面の確かめ方：
  - 長い行、空行、全角スペースで始まる行を含む原稿で、行番号がそれぞれの行の 1 列目の上にあること。
  - 文字サイズと行間を変えても、行番号が列からずれないこと。
  - 開いたときに冒頭が見え、右から左へスクロールできること。
  - 文字を足して列が増えたとき、影の層も同じように増えること。

## トレードオフ

- `textarea` を使うと、縦書きの入力、カーソル、選択、変換を WebView にそのまま任せられる。その代わり、横書きのエディタにある色付け、診断の印、補完を持たない。
- 影の層は、`textarea` と同じ折り返しになることに頼る。WebView の版によって折り返しの規則がずれると、行番号がずれるおそれがある。確かめ方の項目で、版を上げるたびに確かめる。
