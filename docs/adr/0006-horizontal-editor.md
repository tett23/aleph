# ADR 0006: 横書きのエディタ

ステータス: 採択→CodeMirror で作る部分と、複数の章を開いたあいだは横書きとする部分は[ADR 0019](0019-one-editor-for-both-writing-modes.md)

## 文脈

原稿は、組んだときの字詰めを見ながら書きたい。
Golem の `style.toml` は、`[page.grid]` で版面の 1 行の字数（`characters`）とページの行数（`lines`）を、`[page]` で組方向（`writing-mode`）を決めている。

プロトタイプでは CodeMirror 6 でエディタを作り、次のことを試した。

- 本文の列の幅を `characters` の字数に合わせ、組版と同じ字数で折り返した。
- 行番号の左に HEAD からの変更の印を出した。最初は行番号の左に寄せすぎ、次に余白をとりすぎたので、VS Code くらいの間隔に落ち着いた。折り返した行では、行番号を段落の中央ではなく 1 行目にそろえた。
- `.gm` の命令（`@...`、`[name ...]`）と式（`[= ...]`）を等幅にし、散文スロット（`:` の後）は本文のフォントのままにした。`.toml` などのコードは等幅で書いた。
- 改ページの位置を見積もり、エディタの中に印を出した。
- 不可視文字（半角と全角のスペース、タブ、改行）を設定で出せるようにした。
- shift と ⌘ を押しながらツリーの章を選び、複数の章をまとめて開けるようにした。

改ページの見積もりは、段落の字数を字詰めで割って行数を数えるだけで、禁則、ルビ、見出しの扱い、行アキを含まない。
組んだページと一致しないことがある。

## 実装すること

### エディタ

- CodeMirror 6 で書く。`.gm`、`.emet`、`.md`、`.toml`、`.svg`、Mermaid に色付けを持つ。
- `.gm` と `.emet` の色付けは、Golem の LSP の semantic tokens を使う（[ADR 0009](0009-lsp-and-formatting.md)）。命令と式は等幅にし、散文スロットは本文のまま。
- サーバーが応えるまでのあいだは、角括弧の入れ子をスタックで追う簡単な字句の読み方で色を付ける。命令の頭と引数、式、散文スロット、コメント（`%%`）、エスケープ、見出し、コードブロックを区別する。
- 自動保存と ⌘S（[ADR 0011](0011-saving-and-git.md)）、LSP（[ADR 0009](0009-lsp-and-formatting.md)）をつなぐ。

### 字詰め

- 本文（`.gm`、`.md`、`.txt`）の列の幅を、`style.toml` の `characters` の字数にする。設定の「1 行の字数」があればそれを使う。
- 本文のフォントは明朝、コード（`.emet`、`.toml` など）は等幅とする。文字サイズは本文とコードで別に設定でき、行間は本文に効く。既定は本文 16 px、コード 13 px、行間 1.75 とする。

### 溝

左から次の順に並べる。

- **変更の印**：HEAD からの追加、変更、削除を色で示す（[ADR 0011](0011-saving-and-git.md)）。
- **行番号**：折り返した行では 1 行目の高さにそろえる。
- **診断の印**：LSP の診断のある行に、重大度の色の印を出す（[ADR 0009](0009-lsp-and-formatting.md)）。

### 改ページの印

- `.gm` の中に、改ページが入る位置の印（「改ページ 2 → 3」）を出す。
- 位置は Golem から受け取る。Golem に、PDF のページと原稿の行の対応を出す機能を求める（下の「Golem への依頼」）。その機能が入るまでは、プロトタイプと同じ見積もりを使い、印が見積もりであることを表示で示す。
- `@page-break` と `@column-break` の位置には、見積もりでも必ず印を出す。

### 不可視文字

- 設定で、半角スペース（·）、全角スペース（□）、タブ（→）、改行（↵）を出す。ゼロ幅の文字と制御文字は、設定によらず出す。

### 複数の章をまとめて開く

- ツリーで `.gm` を選んだあと、shift を押しながら別の `.gm` を押すとその間の章を、⌘ を押しながら押すとその章を足し引きして、まとめて開く。
- エディタは章ごとに縦に並べ、各章の見出しを上に貼り付ける。保存と変更の印は章ごとに扱う。フォーカスのある章を、右のパネルとステータスバーの対象とする。
- 本文のプレビューは、選んだ章を並べて出す（[ADR 0010](0010-previews.md)）。
- 複数の章を開いているあいだは、エディタは横書きとする（[ADR 0007](0007-vertical-editor.md)）。

### Golem への依頼

- 改ページの位置を正確に出すため、Golem に、PDF の各ページの最初の行が原稿のどの位置か（ファイル、行、列）を JSON で出す機能を依頼する。依頼は、Aleph で実際に見積もりがずれる例を添えて、Golem の側の ADR として出す。

## 実装しないこと

- WYSIWYG の編集（見出しを大きく出すなど）。書くときは原稿の記法のまま書く。
- 改ページの位置を Aleph の中で正確に計算すること。組版は Golem に任せる。
- タブで複数のファイルを並べること（[ADR 0005](0005-layout-and-appearance.md)）。

## テスト設計

- サーバーが応える前の `.gm` の色付け：命令、式、入れ子、散文スロット、コメント、エスケープ、見出し、コードブロックを含む行の列を与え、各字の分類を `node --test` で確かめる。プロトタイプで起きた誤り（見出しの記号の後の文字が見出しにならない）を含める。
- semantic tokens から等幅の範囲を決める関数を確かめる（命令、式、散文スロットを含む行）。
- 改ページの見積もり：`@page-break`、見出し、長い段落、空行の様式と改行の様式の原稿で、印の位置を確かめる。
- 変更の印：基の文書と今の文書の組から、追加、変更、削除の行を出す関数を確かめる（先頭と末尾の共通部分、空の基、全部の削除、大きな文書で打ち切る場合を含める）。
- 画面の確かめ方：折り返した行で、行番号と変更の印と診断の印が 1 行目にそろうこと。文字サイズと行間を変えても、溝がそろったままであること。shift と ⌘ で章を選び、まとめて開いた章のそれぞれを保存できること。

## トレードオフ

- 色付けを semantic tokens に任せると、Golem の記法の変更に Aleph が追従しなくて済む。その代わり、サーバーが応えるまでの短いあいだは簡単な色付けになり、サーバーの応答とずれた色が一瞬出ることがある。
- 列の幅を版面の字数に合わせると、組まれた姿に近い感覚で書ける。その代わり、ウィンドウが広くても列は広がらない。
- 改ページの見積もりは、Golem の機能が入るまで不正確である。印が見積もりであることを示して、組んだページ（[ADR 0010](0010-previews.md)）で確かめる運用とする。
