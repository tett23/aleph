# ADR 0037: 分割を始める条件とやめる条件

ステータス: 採択

## 文脈

[ADR 0024](0024-tabs-and-split.md) は、コマンド `view.split` で「選んでいるタブを右のペインに移して二つに分ける」と決め、分割をやめるのは「右のペインが一つのタブだけを持っていて、それを閉じたとき」とした。

実装は、この二つの文より広い場合を決めている。

- タブが一つだけのペインでは `view.split` を使えない（[app/store.ts](https://github.com/tett23/aleph/blob/4e0248c/app/store.ts#L248-L259) の `split`、[app/editor/panes.ts](https://github.com/tett23/aleph/blob/4e0248c/app/editor/panes.ts#L276-L284) の `when`）。そのタブを右に移すと、左のペインが空になるためである。
- すでに分けているときの `view.split` は、選んでいるタブをもう一方のペインに移す（同じ `split`）。
- 左右のどちらのペインでも、タブがなくなれば分割をやめる。タブを閉じたときも（[app/store.ts](https://github.com/tett23/aleph/blob/4e0248c/app/store.ts#L151-L161) の `removeTab`）、タブをもう一方のペインへドラッグして移したときも（同じファイルの `moveTab`）同じである。

仕様書は実装に合わせて書かれているが、[ADR 0024](0024-tabs-and-split.md) とは食い違う。
[ADR 0021](0021-json-files.md)〜0035 を実装と照らしたレビューで、この食い違いが見つかった。
メンテナーは、今の実装を追認する ADR を書くよう求めた（2026-11-08）。

## 実装すること

- `view.split` は、ペインが一つのときは、そのペインが二つ以上のタブを持つときだけ使える。選んでいるタブを新しい右のペインに移し、右のペインを選ぶ。タブが一つだけのときは、コマンドの一覧に出さず、キーで呼んでも何もしない。
- すでに二つのペインがあるときの `view.split` は、選んでいるタブをもう一方のペインの末尾に移し、そのペインを選ぶ。
- 左右のどちらのペインでも、タブを閉じるか、もう一方へ移すかして、タブがなくなったときは、そのペインを除いて分割をやめる。残ったペインを選ぶ。
- ペインが一つのときに最後のタブを閉じたときは、今までどおり空のペインになる。
- [ADR 0024](0024-tabs-and-split.md) のステータスを「採択→分割を始める条件とやめる条件はADR 0037」とする。

コードは、すでにこのとおりに振る舞う。この ADR で足すのは、下のテストと仕様書の記述である。

## 実装しないこと

- 空のペインを残したままの分割（左だけ、右だけが空の状態）。
- 三つ以上のペインと上下の分割（[ADR 0024](0024-tabs-and-split.md) のとおり入れない）。

## テスト設計

画面の状態の変化を、`node --test` で確かめる（app/tabs.test.ts）。

- タブが一つのペインでは `split` が状態を変えないこと（既存のテスト）。
- 分けたあとの `split` が、選んでいるタブをもう一方のペインの末尾に移し、そのペインを選ぶこと。
- 右のペインの最後のタブを閉じると分割をやめること（既存のテスト）。左のペインの最後のタブを閉じても分割をやめ、右に残ったペインが選ばれること。
- 左のペインの最後のタブを右へ移すと、分割をやめ、移したタブが選ばれること。
- 画面の確かめ方：タブが一つのときにコマンドパレットに「右に分ける」が出ないこと、左のペインのタブをすべて閉じると一つのペインに戻ることを確かめる。

## トレードオフ

- タブが一つのときは分けられないので、一つのシートを左右に並べたいときは、先に別のシートを開いてから分ける。空のペインを残さないことを優先した。
- どちらのペインが空になっても分割をやめるので、左を空にして右だけで書く、という使い方はできない。
