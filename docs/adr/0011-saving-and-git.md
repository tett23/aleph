# ADR 0011: 保存と Git

ステータス: 採択

## 文脈

メンテナーは、Git を最初から組み込み、変更した行を行番号の左に色で示すことを求めた。
保存は 10 秒おき程度で自動で行い、Git へのコミットは 1 日 1 回自動で行い、手動でもコミットできるようにと求めた（2026-11-07）。

プロトタイプでは、git のコマンドを Rust の側から実行した。
変更の印は、HEAD の版（`git show HEAD:パス`）とエディタの文書を行ごとに比べて出した。
1 日 1 回のコミットは、起動時と 1 時間ごとに、その日のコミットがまだのワークスペースで変更があれば `git add -A` して `Autosave 日付` でコミットした。

## 実装すること

### 保存

- 変更のあるシートを、10 秒ごとに保存する。間隔は設定で変えられる。
- ⌘S ですぐに保存する。横書きのエディタでは、設定がオンなら整形してから保存する（[ADR 0009](0009-lsp-and-formatting.md)）。
- シートを閉じるとき、ほかのシートを開くとき、アプリを終えるときに、変更があれば保存する。
- 保存していない変更があるあいだは、ツールバーの題名の横に印を出す。

### 変更の印

- エディタの溝に、HEAD の版からの追加、変更、削除を出す（[ADR 0006](0006-horizontal-editor.md)、[ADR 0007](0007-vertical-editor.md)）。比べる相手は保存した内容ではなく、エディタの今の文書とする。
- HEAD にないファイルは、すべての行を追加とする。
- コミットしたら、比べる相手を新しい HEAD に取り直す。

### コミット

- 1 日 1 回、ワークスペースごとに、変更があれば `git add -A` して、`Autosave YYYY-MM-DD` でコミットする。確かめるのは起動時と 1 時間ごととし、その日にコミットしたかを設定に記録する。設定で切れる（既定はオン）。
- 手動のコミットは、Git のパネル、ツールバーのメニュー、⌘⇧K から行う。メッセージを書いて、`git add -A` してコミットする。
- コミットの前に、開いているシートをすべて保存する。

### Git のパネル

- 左のサイドバーに、変更のあるファイルの一覧、選んだファイルの差分、コミットメッセージ、コミット、push、pull、履歴を出す。
- pull は `--no-rebase` で行う（main を rebase しない運用に合わせる）。
- ツリーの、未コミットの変更があるファイルに印を出す（[ADR 0004](0004-workspaces-and-projects.md)）。

## 実装しないこと

- ブランチの作成と切り替え、マージ、衝突の解決。これらはターミナルか、ほかの Git のツールで行う。Aleph は現在のブランチを出すだけとする。
- 部分的なステージ（ファイルの一部だけのコミット）。
- push の自動化。push は手で行う。

## テスト設計

- 変更の印：基の文書と今の文書から、追加、変更、削除の行を出す関数を `node --test` で確かめる（[ADR 0006](0006-horizontal-editor.md) と同じ関数）。
- 1 日 1 回のコミット：日付、前回コミットした日、変更の有無の組から、コミットするかを決める関数を確かめる。日付が変わった直後、同じ日の 2 回目、変更のない日を含める。
- Git の実行：一時ディレクトリにリポジトリを作り、変更、コミット、HEAD の取り直しを `cargo test` で確かめる。
- 画面の確かめ方：書いてから 10 秒で保存されること。日付をまたいで起動したとき、変更のあるワークスペースだけがコミットされ、同じ日に二度コミットされないこと。⌘⇧K でコミットでき、変更の印が消えること。

## トレードオフ

- 1 日 1 回の自動コミットは、作業の区切りでない時点の状態もコミットする。その代わり、コミットを忘れても 1 日分より多くは失われない。コミットメッセージは日付だけになるので、意味のある区切りは手動のコミットで残す。
- `git add -A` は、ワークスペースの中の未追跡のファイルもすべて入れる。入れたくないものは `.gitignore` に書く。
