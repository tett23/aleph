# ADR 0025: ブックマーク

ステータス: 採択（未実装）

## 文脈

長い原稿を書いていると、よく戻るシート（設定集、人物のメモ）や、書きかけの場所（ある章のある段落）がある。
Aleph でそこへ戻るには、ツリーをたどるか、検索するしかない（[ADR 0004](0004-workspaces-and-projects.md)、[ADR 0015](0015-diagnostics-and-search.md)）。

Obsidian はシートや見出しをブックマークでき、Ulysses はシートをお気に入りにできる。
メンテナーは、Obsidian と Ulysses にあって Aleph にない機能を比べ、これを ADR にするよう求めた（2026-11-07）。

シートのメタデータ（目標、ノート）は、プロジェクトかワークスペースの `.aleph/notes.json` に置いている（[ADR 0012](0012-sheet-goals-and-notes.md)）。

## 実装すること

- ブックマークは、シートか、シートの中の一行を指す。シートのブックマークはパスを、行のブックマークはパスと行の番号とその行の文字を持つ。
- コマンド `bookmark.toggle`（[ADR 0023](0023-command-palette.md)、既定のキーは ⌘D）で、エディタのカーソルの行をブックマークする。すでにその行にブックマークがあれば外す。ツリーの行の右クリックのメニューと、コマンド `bookmark.toggleSheet` で、シートをブックマークする（すでにあれば外す）。
- ブックマークは、ワークスペースごとに、ワークスペースのルートの `.aleph/bookmarks.json` に置く。Git で同期すれば、ほかの機械でも同じブックマークになる。中身は、ブックマークの並び（パスはワークスペースのルートからの相対パス、行の番号は 1 から）とする。
- 左のサイドバーに「ブックマーク」のパネルを足し、リボンにアイコンを足す。上にブックマークの並びを、下に最近開いたシート（[ADR 0026](0026-recent-files.md)）を出す。
  - ブックマークの各行には、シートの名前（`.gm` と `.md` は見出し）と、行のブックマークならその行の文字の初めの 40 字を出す。
  - 押すとそのシートを開き、行のブックマークならその行に移る。
  - ドラッグで並べ替え、× で外す。
  - ファイルが見つからないブックマークは、薄く出し、押すと見つからないことを知らせる。
- 行のブックマークで移るときは、残した行の番号の行の文字が、残した文字と同じかを確かめる。違えば、残した番号から近い順に、同じ文字の行を探してそこに移る。見つからなければ、残した番号の行に移る（行が足し引きされても、たいていはその段落に戻れるように）。移ったあとの番号を残し直す。
- Aleph でファイルの名前を変えたときは、ブックマークのパスも変える。

## 実装しないこと

- 見出しや範囲（複数行）のブックマーク。
- ブックマークのグループやフォルダ。
- エディタの溝に、ブックマークの印を出すこと。
- ワークスペースをまたぐブックマーク。

## テスト設計

DOM に触れない部分を関数に分け、`node --test` で確かめる。テストを先に書いて失敗させてから実装する。

- 足し引き：シートと行のブックマークを足すこと、同じものを足すと外れること、並べ替え、外すこと。
- 読み書き：`.aleph/bookmarks.json` の中身を読んで書くと同じになること、形の違う項目を読み飛ばすこと、ファイルがないときは空の並びになること。
- 行を探し直す：残した番号の行の文字が同じならそこ、違えば近い順に同じ文字の行（前後で同じ距離なら前）、見つからなければ残した番号（文書の行数を超えるときは最後の行）を返すこと。
- 名前の変更：パスが変わること、フォルダの名前を変えたときはその下のパスがすべて変わること。
- 画面の確かめ方：見本のプロジェクトで、⌘D で行をブックマークし、上に何行か足してからパネルで押すと、その段落に戻ること、シートのブックマーク、並べ替え、外すこと、ファイルの名前の変更でブックマークが付いてくることを確かめる。

## トレードオフ

- ブックマークをワークスペースのファイルに置くので、Git の差分に出る。機械ごとに違うブックマークは持てない。その代わり、ほかの機械でも同じ場所に戻れる。
- 行を文字で探し直すので、同じ文字の行が多い場所（空の行、短い記号の行）では、違う行に移ることがある。
