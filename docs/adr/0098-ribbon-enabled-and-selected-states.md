# ADR 0098: リボンの選択状態と無効状態を区別する

Status: proposed

## 文脈

指示者は、開いていないリボンの項目がグレーになっていることを指摘し、プロットがない場合は無効であると示すよう求めた（2026-11-22）。
使えるが選んでいない状態と、使えない状態を区別する。

## 調査した事項

調査したコードは `d62c18cb9dcc65304dd1b1c50379eb04d24fb393` である。
[`mountShell`](https://github.com/tett23/aleph/blob/d62c18cb9dcc65304dd1b1c50379eb04d24fb393/app/ui/shell.ts) はリボンの項目を `span.iconbtn` として作り、`renderRibbon` は `on` クラスだけを切り替える。
[`app/style.css`](https://github.com/tett23/aleph/blob/d62c18cb9dcc65304dd1b1c50379eb04d24fb393/app/style.css#L57) は通常のアイコンに `--text-2` を使う。
実行中のリリース版のライト表示でも、未選択のアイコンが灰色で表示されることを確認した。

[`view.plot`](https://github.com/tett23/aleph/blob/d62c18cb9dcc65304dd1b1c50379eb04d24fb393/app/palette.ts#L212) はシートまたは表示中のプロットからプロジェクトを求めるが、`plot.csv` の存在は条件にしていない。
[`plotRows`](https://github.com/tett23/aleph/blob/d62c18cb9dcc65304dd1b1c50379eb04d24fb393/app/plot/mount.ts#L18) は読み込みの失敗を空文字列として扱うため、プロットなしと空のプロットを区別できない。

## 実装すること

リボンの項目を「使えて未選択」「使えて選択中」「無効」の三状態で表示する。
使える項目は選択の有無によらず通常の文字色 `--text` を使い、選択中だけ無彩色の背景と選択の印を付ける。
無効な項目だけを薄い色にし、マウスを乗せても有効な項目と同じ強調をしない。
ライトとダークの両方で同じ状態の区別を保つ。

リボンをボタンとして操作できるようにし、項目名をアクセシブルな名前として付ける。
選択中は `aria-pressed`、無効時は `disabled` で状態を伝える。
無効な項目をクリックしてもキーボードで操作してもコマンドを実行しない。
項目は隠さず、プロットが無効ならツールチップに理由を示す。

プロットの対象プロジェクトは `view.plot` の現在の選択規則にそろえる。
対象がない、`plot.csv` が存在しない、存在確認中、読み取りに失敗した場合は無効とする。
ヘッダーだけでデータ行が0件の `plot.csv` は、存在するプロットとして有効にする。
読み取り失敗は「プロットがありません」とはせず、読み取れないことを知らせる。
プロジェクトの切り替えとファイルの作成、削除、改名で再判定し、古い非同期結果を適用しない。
リボン、コマンドパレット、ショートカットは同じ可否の判定を使い、実行直前にも確かめる。
差分を含むほかの項目は既存のコマンドの可否を使う。

[ADR 0005](0005-layout-and-appearance.md) のリボンの見た目と [ADR 0023](0023-command-palette.md) のプロットの実行条件を補足する。
実装時に仕様書と日英 README に三状態とプロットの条件を書く。

## 実装しないこと

アイコンの種類や並び順の変更、プロットの自動作成、本文が空であることを理由にした無効化。

## 不変条件

- I1: 使えるリボン項目の通常時の前景色は選択状態に依存せず、選択中だけに選択の印が付く。
- I2: プロットの操作は、現在の対象に読み取れる `plot.csv` が存在すると確認できたときだけ有効である。
- I3: 無効な項目への操作でコマンドが実行される回数は0である。
- I4: リボン、パレット、ショートカットのプロットの可否は一致し、古い対象の確認結果では変わらない。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 閉じたファイル一覧、開いたファイル一覧 | 両方が通常色、後者だけ選択の印 | I1 |
| プロジェクトなし、ファイルなし、確認中 | プロット無効 | I2, I3 |
| ヘッダーだけのプロット | プロット有効 | I2 |
| 確認後にファイルを削除 | 無効に変わり、実行しない | I2, I3 |
| 確認中にプロジェクトを切り替え | 古い結果を無視 | I4 |

## 受けいれ条件

- A1: 明暗両モードで、使える未選択項目と無効なプロットを見分けられる。
- A2: プロットを作成、削除すると、再起動せずに可否と理由が更新される。

## テスト設計

状態判定と操作抑止を `ADR 0098 I1: …` の形で先にテストする。
DOM のテストで色に対応するクラス、ボタン属性、選択の印を調べる。
ファイル確認の遅延、失敗、逆順完了と、実行直前の削除を注入して I2 から I4 を確かめる。
A1 と A2 は Tauri の実画面で確認する。

## トレードオフ

未選択の項目も通常色にするとリボンの視覚的な強さが増すが、無効状態との区別は明確になる。
存在確認中は一時的にプロットを操作できない。
