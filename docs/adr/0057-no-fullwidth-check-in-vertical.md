# ADR 0057: 縦組みのシートでは、全角の英数字の検査をしない

ステータス: 採択

## 文脈

文章の検査（[ADR 0030](0030-spelling-and-grammar.md)）の「全角の英数字」は、Ａ〜Ｚ、ａ〜ｚ、０〜９ の全角の文字が続くところに、情報の診断を出す（[app/proofread.ts](https://github.com/tett23/aleph/blob/de1df29/app/proofread.ts#L142)）。
この検査は、英数字を半角で書く横組みの原稿を前提にしている。

縦組みの原稿では、英数字を全角で書くほうがよい。
半角の英数字は縦組みで横に倒れて並び、全角なら一字ずつ立って並ぶからである。
実際に、縦組みの原稿（`style.toml` の `[page]` が `writing-mode = "vertical"`）の一つの章で、寮の名前の「Ｓ４」に 13 件の診断が付き、問題のパネル（[ADR 0055](0055-problems-panel.md)）がそれで埋まった。
書き手が正しく書いた箇所に診断が出ている。

シートが縦組みかどうかは、プロジェクトの `style.toml` から読んだ字詰めの `vertical` で分かる（[app/docs.ts](https://github.com/tett23/aleph/blob/de1df29/app/docs.ts#L10)）。
ステータスバーの「縦組み」の表示も、これを使っている。

## 実装すること

- 全角の英数字の検査を、縦組みのシート（字詰めの `vertical` が真）では行わない。
  - 縦組みかどうかは、プロジェクトの `style.toml` の組み方向で決める。ツールバーの「縦」「横」（エディタの見た目の切り替え）では決めない。
  - プロジェクトの外のシート（`style.toml` がない）は横組みとし、これまでどおり検査する。
- ほかの検査（ら抜き言葉、表記ゆれ、句読点の連続、半角の片仮名、英語の綴り）は、縦組みでも変えない。
- `style.toml` を保存して組み方向が変わったら、開いているシートの検査をやり直す。
- 設定の「全角の英数字」の説明に「縦組みのシートでは検査しない」と添える。
- 仕様書の文章の検査の節を書き直す。

## 実装しないこと

- 縦組みのシートで、半角の英数字に診断を出すこと（逆向きの検査）。縦中横で半角を使う書き方もあり、どこまで全角にするかの規則を決めてから、別の ADR で扱う。
- 無視する語を、全角の英数字の検査に効かせること。横組みで全角の固有名を使う原稿が出てきたら、別の ADR で扱う。
- 組み方向を、シートごとや設定で上書きすること。

## テスト設計

`node --test` で、テストを先に書いて失敗させてから実装する。

- 検査の関数が、縦組みのとき「Ｓ４」に全角の英数字の診断を出さないこと。
- 横組みのとき、これまでどおり「Ｓ４」に診断を出すこと。
- 縦組みでも、句読点の連続と半角の片仮名の診断は出ること。
- 画面の確かめ方：試験のプロジェクトの章に「Ｓ４」を書き、`style.toml` が横組みのとき診断が出て、`writing-mode = "vertical"` にして保存すると診断が消えることを確かめる。

## トレードオフ

- 縦組みの原稿で、誤って全角にした英数字（横組みの部分に流用する文など）は見逃す。縦組みでは全角が正しい書き方なので、診断を出さないほうを選ぶ。
- 組み方向をプロジェクトの `style.toml` から読むので、同じプロジェクトで縦と横を混ぜる書き方には合わない。Golem の組み方向もプロジェクトごとである。
