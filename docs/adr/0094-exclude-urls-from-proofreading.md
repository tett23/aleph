# ADR 0094: URL を校正の対象から除く

Status: accepted

## 文脈

指示者は、URL を URL として認識し、校正の info を出さないことを求めた（2026-11-22）。
ドメイン名やパスの文字列を英単語として検査すると、本文を直すための情報に不要な指摘が混ざる。

## 調査した事項

調査したコミットは `8a102bdfa38df9fb2fa7a0852a5ca7da39d186af` である。
[`mdOut`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/proofread.ts#L55) は Markdown のリンク先を除くが、裸の URL の除外は持たない。
同ファイルの `segments` は `.txt` の行全体を検査範囲にし、`englishWords` は検査範囲から英単語を取り出す。
[ADR 0030](0030-spelling-and-grammar.md) は Markdown のリンク先を除外し、`.txt` は全体を検査すると決めている。

## 実装すること

校正対象の `.gm`、`.md`、`.txt` で、本文中の絶対 URL の範囲を検査対象から除く。
対象は大文字小文字を区別しない `http://` と `https://` で始まり、ホストが空でない URL とする。
裸の URL と `<https://example.com>` のような山括弧付きの URL を扱う。
除外は既存のコードと命令とリンク先の除外に重ねる。

URL 候補は空白、改行、制御文字、山括弧、引用符、日本語の括弧、`。`、`、` で区切る。
候補末尾の `.`、`,`、`!`、`?`、`;`、`:` は本文の句読点として残す。
丸括弧と角括弧は候補内で対応するものを URL に含め、対応する開き括弧のない閉じ括弧は候補の終わりにする。
この範囲の文字列が URL として解析でき、上記のスキームとホストを満たす場合にだけ除外する。
日本語のパスは URL に含めるため、URL の直後に区切りなく続けた日本語の本文とは区別しない。

除いた範囲は英語の綴り検査へ渡さず、ほかの校正规則にも渡さない。
URL の両側の本文を連結して規則を当てない。
既存の LSP 診断には影響させない。
URL の表示、クリックで開く動作、プレビューのリンク生成は変更しない。

採択時に [ADR 0030](0030-spelling-and-grammar.md) の「検査する範囲」を補足する変更を記録する。
実装時に仕様書と README に除外の対象を書く。

## 実装しないこと

通信による URL の有効性確認、`www.example.com` の推測、メールアドレスと HTTP 以外のスキームの追加対応。

## 不変条件

- I1: 認識した URL と重なる校正診断および綴り検査への問い合わせ対象は0件である。
- I2: 除外した URL の外の本文には従来の校正规則を適用し、診断位置は元の文書の UTF-16 位置に一致する。
- I3: URL を除いた前後の範囲を、連続した一つの検査範囲にしない。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 空、URL だけ | URL に校正診断なし | I1 |
| クエリ、フラグメント、日本語パス付き URL | URL の全範囲を除外 | I1 |
| `<https://example.com>`、`(https://example.com/a)` | 括弧を本文に残す | I1, I2 |
| `https://example.com/a(b)` | 対応する括弧を URL に含める | I1 |
| `https://example.com。見れる` | `見れる` の指摘を元の位置に出す | I2 |
| ホストのない `https://`、通常の英語 | 従来どおり検査 | I2 |
| URL の両側に規則の文字列を分割 | 結合した誤検出なし | I3 |

## 受けいれ条件

- A1: 三形式のシートに同じ URL と誤綴りの本文を置くと、URL には校正の info が出ず、本文には出る。
- A2: URL を編集して通常の文字列にすると校正が再開する。

## テスト設計

`ADR 0094 I1: …` の形で境界表を各形式について検査し、裸の URL のテストを先に失敗させる。
綴り検査の代わりに渡した語を記録する関数を使い、URL の語を問い合わせないことも検査する。
既存のコード除外とリンク表示名の検査が残ること、URL 前にサロゲートペアがある場合の位置を確かめる。
A1 と A2 はエディタと診断一覧で確認する。

## トレードオフ

句読点の除去で日本語本文を誤って除外しにくくなるが、句読点で終わる URL とは区別できない場合がある。
通信せず構文だけで判断するので、存在しない URL も除外する。
