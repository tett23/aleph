# ADR 0047: プレビューで外部の画像を読み込まない

ステータス: 採択（未実装）

## 文脈

Markdown のプレビューは、`![…](https://…)` をそのまま `<img src>` にするので、プレビューを開いた時点で外部へ要求が出る（[app/md.ts](https://github.com/tett23/aleph/blob/b4ee3c4/app/md.ts#L348)）。
Mermaid の `image` の図形も同じである。
Golem の HTML の画像は、`data-src` に移してローカルのファイルとして読む（[app/preview/render.ts](https://github.com/tett23/aleph/blob/b4ee3c4/app/preview/render.ts#L40-L49)）ので、外部には出ない。
2026-11-08 のセキュリティ監査（[docs/audit/2026-11-08-security.md](../audit/2026-11-08-security.md) の所見 6）は、共有された文書を開いたことが、IP アドレスと時刻とともに相手に伝わることを指摘した。
メンテナーは、監査の修正をすべて ADR にするよう求めた（2026-11-08）。

## 実装すること

- Markdown のプレビューの画像（`![…](…)` と、埋め込みの画像）は、ローカルのファイルだけを読む。`src` は、シートのディレクトリからの相対のパスとして解決し、ワークスペースの中にあれば `data-src` に移して、Golem の HTML と同じ読み方（`fileUrl`）で出す。
- `http:`、`https:` などの外部の画像は読み込まず、代替テキストと URL を枠の中に文字で出す（「外部の画像は読み込みません：<URL>」）。
- Mermaid の図は、描いた SVG の中の外部の `href` と `xlink:href` を持つ `image` を、描いたあとに取り除く。
- [ADR 0042](0042-ipc-trust-boundary.md) の CSP の `img-src`（`'self' blob: data:`）で、取りこぼしも止める。

## 実装しないこと

- 外部の画像を読み込む設定や、文書ごとに読み込みを許す操作。
- 外部の画像を取ってきてワークスペースに保存すること。

## テスト設計

`node --test` で、テストを先に書いて失敗させてから実装する。

- `markdownHtml` が、相対のパスの画像を `data-src` にし、`https:` の画像を文字の知らせにすること、`..` でワークスペースの外に出るパスを落とすこと。
- Mermaid の描いた SVG から外部の `image` を取り除く関数が、ローカルの参照を残すこと。
- 画面の確かめ方：外部の画像と相対のパスの画像を並べた `.md` のプレビューで、相対の画像だけが出て、外部の画像の場所に知らせが出ることを確かめる。

## トレードオフ

- ウェブの画像を貼った Markdown は、プレビューで画像が見えなくなる。開いたことを相手に知られないことを優先した。
