# ADR 0018: ツリーの画像をエディタにドラッグして図版を差し込む

ステータス: 採択

## 文脈

[ADR 0014](0014-shared-library-and-assets.md) は、Finder から `.gm` のエディタに画像を落とすと、プロジェクトの `images/` にコピーして `@figure` を差し込むと決めた。
すでにプロジェクトにある画像を図版にするには、Finder でその画像を探して落とすか、`@figure` の行を手で書くしかない。
メンテナーから、サイドバーのツリーにある画像をドラッグして `.gm` に差し込めるようにと求められた（2026-11-07）。

Finder からのドロップは、Tauri のドラッグアンドドロップのイベントで受けている（[ADR 0014](0014-shared-library-and-assets.md)）。
このイベントはアプリの外から来たファイルのためのもので、ツリーの行はアプリの中の要素なので、別の仕組みが要る。
プロットの表の行の並べ替えは、ドラッグをマウスのイベントで追って実装した（[ADR 0013](0013-plot-and-gantt-chart.md)）。

## 実装すること

- ツリーの画像の行（PNG、JPEG、SVG、PDF。Golem の `@figure` が受ける形式）を、マウスで押したまま 4 ピクセル以上動かすと、ドラッグを始める。動かさずに離したときは、今までどおりその画像を開く。
- ドラッグはマウスのイベントで追う。ポインタに画像の名前を添え、横書きのエディタの上では、`@figure` を差し込む位置（ポインタの下の行の後）に線を出す。Esc で取り消す。
- `.gm` の横書きのエディタの上で離すと、ポインタの下の行の後に、[ADR 0014](0014-shared-library-and-assets.md) と同じ形で `@figure <パス> alt="<名前>"` と字下げしたキャプションの行を差し込む。一回の変更として当て、⌘Z で一度に戻せる。
- パスは次のように決める。
  - 画像がその章と同じプロジェクトの中にあれば、コピーせず、プロジェクトのルートからのパスを書く（`images/` の外にあってもよい）。
  - ほかのプロジェクトや、プロジェクトの外にある画像は、その章のプロジェクトの `images/` に、[ADR 0014](0014-shared-library-and-assets.md) と同じく名前の衝突を避けてコピーし、そのパスを書く。
- `.gm` でないエディタ、プロジェクトの外の `.gm`、縦書きのエディタの上で離したときは、何も差し込まず、差し込めない理由を通知する。それ以外の場所で離したときは、何もしない。

## 実装しないこと

- 縦書きのエディタへの差し込み（縦書きのエディタは CodeMirror でなく、行の位置の求め方が違う。[ADR 0007](0007-vertical-editor.md)）。
- 複数の画像をまとめてドラッグすること。
- 画像でないファイルのドラッグ（`.emet` の `@import` の差し込みなど）。
- ツリーの中でファイルを動かすこと。

## テスト設計

- パスの決め方：同じプロジェクトの `images/` の画像、同じプロジェクトの `images/` の外の画像、ほかのプロジェクトの画像、プロジェクトの外の画像、`@figure` が受けない形式（GIF など）で、差し込むパスとコピーの要否を `node --test` で確かめる。
- 差し込む内容は [ADR 0014](0014-shared-library-and-assets.md) のテスト（空の行、文字のある行、文書の末尾）と同じ関数を使うので、その関数のテストで足りる。
- 画面の確かめ方：ツリーの画像を章の途中の行にドラッグすると、その行の後に `@figure` が入り、⌘Z で一度に戻ること。ほかのプロジェクトの画像を落とすと `images/` にコピーされること。動かさずに押した画像の行は、今までどおり開くこと。Esc で取り消せること。

## トレードオフ

- マウスのイベントで追うので、ブラウザのドラッグアンドドロップ（`draggable`）の振る舞い（カーソルの形、ほかのアプリへの持ち出し）は得られない。その代わり、Finder からのドロップを受ける Tauri のイベントと仕組みが重ならず、差し込む位置の線を自分で描ける。
- 同じプロジェクトの画像はコピーしないので、画像を消したり名前を変えたりすると、`@figure` のパスが切れる。切れたパスは、Golem の check が G02033（「ファイルがありません」）として報告する（golem 0.1.0-rc3 で確かめた）。
