# ADR 0022: ⌘P でシートを名前から開く

ステータス: 採択（未実装）

## 文脈

Aleph でシートを開くには、左のサイドバーのツリーをたどって押すか、検索（[ADR 0015](0015-diagnostics-and-search.md)）の結果を押す（[ADR 0004](0004-workspaces-and-projects.md)）。
ツリーは開いたフォルダしか見せないので、深い場所のシートや、名前は覚えているが場所を覚えていないシートを開くには手間がかかる。

Obsidian と Ulysses は、名前の一部を打つと候補が絞られ、キーボードだけで開ける画面（クイックオープン、⌘O）を持つ。
メンテナーは、Obsidian と Ulysses にあって Aleph にない機能を比べ、これを ADR にするよう求めた（2026-11-07）。
下書きのレビューでは、キーを VS Code と同じ ⌘P にし、同じ入力欄の先頭に `>` を打つとコマンドを絞り込むようにするよう求められた（2026-11-08、[ADR 0023](0023-command-palette.md)）。
VS Code では、ファイルを名前で開く Quick Open（⌘P）と、コマンドパレット（⇧⌘P）が、一つの入力欄を共有している。

ツリーは、ワークスペースの全体の項目をすでに読んでいる（[app/ui/tree.ts](https://github.com/tett23/aleph/blob/556db161917fdf32808b5b5153fdce0a99c65c71/app/ui/tree.ts#L29-L35)）。
`.gm` と `.md` には、最初の見出しを名前として出している（`ctx.titles`）。

## 実装すること

- ⌘P で、画面の上の中央に入力欄と候補の一覧を出す。この操作はコマンド `file.quickOpen` とし、キーは [ADR 0034](0034-key-bindings.md) の割り当てで変えられる。
- 入力欄の先頭が `>` のときは、シートではなくコマンドを絞り込む（[ADR 0023](0023-command-palette.md)）。`>` を消すと、シートの候補に戻る。この ADR の照らし合わせは、`>` で始まらない入力に使う。
- 候補は、今のワークスペースのうち、ツリーに出すファイル（Aleph が開ける形式で、`.` で始まらないもの）すべてとする。畳んだフォルダの中のものも含む。
- 入力が空のときは、最近開いたシート（[ADR 0026](0026-recent-files.md)）を新しい順に出す。
- 入力があるときは、各候補の二つの文字列と、あいまいに照らし合わせる。一つはワークスペースのルートからのパスで、もう一つは見出しから取った名前（`.gm` と `.md` のツリーに出す名前）である。
  - 照らし合わせは、入力の文字が候補の中に同じ順で現れるかを見る（部分列）。大文字と小文字は区別しない。かなと漢字の読みの変換はしない。
  - 点数は、続けて一致した文字、単語の先頭（`/`、`-`、`_`、`.`、空白の後、大文字の始まり）での一致、ファイル名の部分での一致に加点し、一致のあいだの隙間に減点する。名前とパスのうち高いほうを取る。
  - 最近開いたシートには、新しいものほど大きな加点をする。
  - 点数の高い順に、上位 50 件を出す。一致した文字を太字にする。
- 一覧の各行には、名前（見出しがあれば見出し、なければファイル名）と、薄くパスを出す。
- ↑↓ で選び、↩ で開く（ツリーで押したときと同じく、今のシートと入れ替える）。⌘↩ では新しいタブに開く（[ADR 0024](0024-tabs-and-split.md)）。Esc か、一覧の外を押すと閉じる。
- 開いているあいだは、入力欄にフォーカスを置き、エディタにはキーを渡さない。

## 実装しないこと

- 中身の検索（左のサイドバーの検索の役目とする）。
- ほかのワークスペースのファイル。
- フォルダを開くこと。
- `>` 以外の先頭の記号（VS Code の `:` の行の番号、`@` の見出しなど）。
- ローマ字や読みでの一致。

## テスト設計

DOM に触れない部分を関数に分け、`node --test` で確かめる。テストを先に書いて失敗させてから実装する。

- あいまいな照らし合わせ：部分列として一致するとき、一致の位置と点数を返し、一致しないとき null を返すこと。大文字と小文字を区別しないこと。続けて一致したもの、単語の先頭で一致したもの、ファイル名で一致したものが、そうでないものより高いこと。日本語の名前（例：「霧笛」で「霧笛」と「霧の笛」）、サロゲートペアを含む名前で位置がずれないこと。
- 候補の並べ方：パスと名前の高いほうを取ること、最近開いたシートの加点、上位 50 件で切ること、入力が空のときは最近開いた順になること、ツリーに出さないファイルが入らないこと。
- 入力の振り分け：`>` で始まる入力はコマンドの絞り込みに、そうでない入力はシートの絞り込みに渡ること（`>` の後の空白は読み飛ばす）。
- 画面の確かめ方：見本のワークスペースで、⌘P から名前の一部を打って開けること、↑↓ と ↩ と Esc で操作できること、⌘↩ で新しいタブに開くこと、先頭に `>` を打つとコマンドの一覧に変わり、消すとシートの一覧に戻ることを確かめる。

## トレードオフ

- 部分列の照らし合わせは単純で速いが、打ち間違いには弱い。打ち間違いを許す照らし合わせ（編集距離など）は候補が増えすぎるので使わない。
- 候補をツリーが読んだ項目から作るので、ツリーを読み直すまでは、Aleph の外で足したファイルが候補に出ない。
