# ADR 0093: 拡張子なしで作るシートの形式を尋ねる

Status: accepted-pending

## 文脈

指示者から、拡張子を付けずに作ったシートが認識されないとの報告があった（2026-11-22）。
拡張子のない名前を入力した場合は、Markdown と Golem のどちらで作るか尋ねる。

## 調査した事項

調査したコミットは `8a102bdfa38df9fb2fa7a0852a5ca7da39d186af` である。
[`createAt`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/ui/tree.ts#L205) は、右クリックで作るシートについて常に種類を尋ねる。
同ファイルの `new-file` は、プロジェクト外では入力した名前をそのまま `writeText` に渡す。
[`ext`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/path.ts#L5) は拡張子を小文字にして返し、先頭だけのドットと末尾のドットは拡張子として返さない。

## 実装すること

「新しいシート」で名前を確定した後、最終ファイル名に拡張子がなければ「シートの形式」を尋ねる。
選択肢は「Markdown (.md)」「Golem (.gm)」「やめる」とし、選ぶまではファイルを作らない。
選んだ拡張子を一度だけ付け、その形式として開く。
末尾のドットは除いてから拡張子を付け、名前全体が空、`.`、`..` になる入力は拒否する。
`.メモ` のような先頭のドットだけの名前も拡張子なしとして扱う。

`.md` や `.gm` を含む既存の拡張子付きの入力には、この質問を出さない。
未対応の拡張子の扱いは既存のままとし、暗黙に `.md` や `.gm` を追加しない。
右クリックの「シートを追加」は、[ADR 0065](0065-tree-create-and-convert.md) の種類選択を維持し、同じ質問を重ねない。
プロジェクト内の新規シートで拡張子を省略した場合にも質問する。
そこで `.gm` を選べば従来の章登録を行い、`.md` を選べば同じ作成先に作るが Golem の章には登録しない。
既存の `.gm` 指定時の章登録は維持する。

ファイルの存在確認は拡張子を確定してから行い、同名ファイルを上書きしない。
取消ではファイルも manifest も変更しない。
名前の検証と作成先の制限は既存の各操作に従う。
採択時に [ADR 0065](0065-tree-create-and-convert.md) の「既存の新規シート操作」の決定の変更を記録し、実装時に仕様書と README を更新する。

## 実装しないこと

既存の拡張子なしファイルの改名、既存ファイルの形式推定、右クリックの作成形式の削減。

## 不変条件

- I1: 拡張子なしの新規シートは、形式を選んで成功したときだけ、選んだ拡張子を持つファイルが1個増える。
- I2: 取消、無効な名前、確定後の名前の衝突ではファイルと manifest は変わらない。
- I3: 拡張子付きの入力には形式を推測する質問も追加の拡張子も付かない。
- I4: 新規シート操作でプロジェクトの章に登録するのは `.gm` だけである。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| `メモ`、md を選択 | `メモ.md` を作る | I1 |
| `メモ.`、gm を選択 | `メモ.gm` を作る | I1 |
| `.メモ`、md を選択 | `.メモ.md` を作る | I1 |
| `メモ.MD`、`図.svg` | 入力の拡張子を保つ | I3 |
| 空、`.`、`..`、取消、同名 | 書き込みなし | I2 |
| プロジェクトで md、gm を選択 | gm だけを章登録 | I4 |

## 受けいれ条件

- A1: プロジェクトの内外で、拡張子なしの名前から `.md` と `.gm` をそれぞれ作り、対応するエディタで開ける。
- A2: 右クリックの種類選択で、既存の全形式を作成できる。

## テスト設計

`ADR 0093 I1: …` の形で名前の解決、質問の回数、書き込みと章登録を検査する。
拡張子なしの `new-file` のテストを先に失敗させる。
I2 は作成先のファイル一覧と manifest の前後を比較する。
A1 と A2 は画面から作成して、ツリーへの表示とエディタの形式を確認する。

## トレードオフ

形式を推測せず尋ねるため操作が一つ増えるが、書き手の意図した形式で保存できる。
右クリックでは既に種類を指定できるため、その選択を優先する。
