# ADR 0015: 診断と検索

ステータス: 採択

## 文脈

メンテナーは、preflight の診断の一覧と lint の結果を出せるようにと求めた。
続けて、ステータスバーの LSP の隣に lint と preflight を出し、エラーがあれば赤、警告なら黄色、notice なら青にするようにと求めた。
検索は、プロジェクトの中と全プロジェクトで、正規表現も使えるようにと求めた（2026-11-07）。

`golem check`、`golem lint`、`golem preflight` は、`--format json` で診断の配列を出す。
各要素は、コード、**重大度**（`error`、`warning`、`notice`、`info`）、位置（ファイル、行、列）、文言、関連の情報を持つ。
三つとも、JSON を標準エラー出力に書き、標準出力には何も書かない（Golem の仕様書の「diagnostics と終了コード」、golem 0.1.0-rc3 で確かめた）。
プロトタイプは「check と lint は標準出力、preflight は標準エラー出力」と誤って読み、両方を試す回避策を書いていた。
また preflight は `-v` を受け付けない。

## 実装すること

### 診断のパネル

- 左のサイドバーの「診断」で、プロジェクトを選び、check、lint、preflight のどれかを実行する。
- 結果はファイルごとにまとめ、重大度の順、ファイルの順、行の順に並べる。各項目に、重大度の印、文言、コード、行と列、関連の情報を出す。項目を押すと、そのファイルのその位置を開く。
- JSON は標準エラー出力から読む。JSON の配列として読めないとき（golem が起動できなかったなど）は、出力をそのまま出す。
- check と lint には `-v` を付けて info も受け取り、preflight には付けない。

### ステータスバー

- ステータスバーの LSP の隣に、lint と preflight の状態を出す。色は、エラーがあれば赤、警告があれば黄、notice があれば青、それ以外（info だけのときと何もないとき）は緑とする。件数は error、warning、notice の合計を添え、info は数えない。実行していないときと実行中は薄く出す。
- プロジェクトを開いたときと、`.gm`、`.emet`、`.toml` を保存して 2.5 秒たったときに、lint、preflight の順に裏で実行する。
- 押すと、診断のパネルにその結果を出す。

### 検索

- 左のサイドバーの「検索」で、このプロジェクト、このワークスペース、すべてのワークスペースのどれかを範囲にして検索する。
- 正規表現と、大文字と小文字の区別を切り替えられる。
- 検索は Rust の側で、`.gitignore` に従ってファイルを走査して行う（`ignore` と `regex`）。対象は Aleph が開くテキストの形式とする。結果は 2000 件で打ち切る。
- 結果はファイルごとにまとめ、一致した部分の前後とともに出す。押すとその位置を開く。
- 入力欄は描き直さず、結果だけを描き直す。入力の途中で文字が落ちないようにするためである（プロトタイプで起きた）。

## 実装しないこと

- 置換。
- 診断の自動の修正（`fixes` の適用）。Golem の側の対応を見てから決める。
- 保存のたびの check。check は LSP と内容が重なるので、パネルからの実行だけとする。

## テスト設計

- JSON の読み方：標準エラー出力の配列、空の配列、壊れた JSON、出力がない場合を `node --test` で確かめる。check、lint、preflight の実際の出力を一度ずつ記録したものを試料に含める。
- 並び：重大度、ファイル、行の順に並ぶことを確かめる。
- ステータスバーの色：エラー、警告、notice、info だけ、空、実行できなかった場合の色を確かめる。
- 検索：一時ディレクトリで、正規表現、大文字と小文字、`.gitignore` で除くファイル、日本語の文字の位置（文字の数え方）を `cargo test` で確かめる。
- 画面の確かめ方：見本のプロジェクトで preflight が赤になり、押すと一覧が開き、項目を押すと `style.toml` が開くこと。検索の入力欄に続けて打っても文字が落ちないこと。

## トレードオフ

- 保存のたびに lint と preflight を走らせると、PDF を組む分の時間と CPU を使う。見本の原稿では数秒で終わるが、長い原稿では遅くなりうる。遅いときは、ステータスバーの更新が遅れるだけで、編集は止めない。
- 置換を持たないので、まとめて書き換えるときは、ほかのエディタか sed を使う。
