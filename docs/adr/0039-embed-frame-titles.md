# ADR 0039: 埋め込みの枠の見出しにシートの名前を出す

ステータス: 採択（未実装）

## 文脈

[ADR 0029](0029-embeds.md) は、プレビューの埋め込みを枠で囲み、見出しに行き先の名前（`#見出し` があれば `名前 > 見出し`）を出すと決めた。
Aleph がシートの名前と呼ぶのは、`.gm` と `.md` の最初の見出しである（[ADR 0027](0027-wikilinks-in-markdown.md)、ツリーの表示と同じ）。

実装は、埋め込みに書かれた行き先の文字をそのまま見出しに出す（[app/embed.ts](https://github.com/tett23/aleph/blob/3ec575e/app/embed.ts#L66-L80)）。
`![[chapters/01]]` と書けば `chapters/01` と出て、その章の名前（「霧笛」など）は出ない。
[ADR 0021](0021-json-files.md)〜0035 を実装と照らしたレビューで、この食い違いが見つかった。
メンテナーは、レビューで残った点のすべてについて ADR を書くよう求めた（2026-11-08）。

## 実装すること

- 埋め込みの枠の見出しは、行き先のシートの名前とする。名前は、ツリーと同じく `.gm` と `.md` の最初の見出しで、なければファイル名（拡張子なし）とする。
- `#見出し` があれば `名前 > 見出し` とする。
- 書いた行き先がシートの名前と違うときは、見出しの右に、書いた行き先を薄く添える（`霧笛　chapters/01`）。同じときは添えない。
- 行き先が見つからないときは、今までどおり書いた行き先を出す。画像の埋め込みは、ファイル名を出す。
- 名前を引く処理は、埋め込みの読み出しの関数（`EmbedIo`）に `name(path)` を足して渡す。名前を渡されないとき（テストなど）は、今の振る舞いのままとする。

## 実装しないこと

- 枠の見出しの書き方を、埋め込みの書き方（`![[行き先|表示する文字]]` など）で変えること。
- エディタの中の埋め込みの行に、名前を出すこと。

## テスト設計

`node --test` で、テストを先に書いて失敗させてから実装する（app/embed.test.ts）。

- 名前のあるシートで、見出しが名前になり、書いた行き先が添えられること。
- 書いた行き先が名前と同じとき、添えないこと。
- `#見出し` のとき `名前 > 見出し` になること。
- 名前のないシートでファイル名になること、見つからない行き先で書いた行き先のままであること、画像でファイル名になること。
- 画面の確かめ方：章をパスで埋め込んだメモのプレビューで、枠の見出しに章の名前と、薄くパスが出ることを確かめる。

## トレードオフ

- 見出しにシートの名前を出すので、名前を変えるとプレビューの見出しも変わる。書いた文字ではなく、行き先そのものを示すことを優先した。
