# ADR 0026: 最近開いたシート

ステータス: 採択（未実装）

## 文脈

Aleph は、最後に開いていたシートを覚えていない。
画面の状態のうち、パネル、縦と横、プレビュー、開いたフォルダ、ワークスペースは `config.json` の `ui` に残して次に起動したときに戻すが（[app/main.ts](https://github.com/tett23/aleph/blob/556db161917fdf32808b5b5153fdce0a99c65c71/app/main.ts#L32-L35)）、開いたシートの履歴はない。
直前まで書いていたシートや、行き来しているいくつかのシートへ戻るにも、ツリーをたどることになる。

Obsidian は最近開いたファイルを出し、クイックオープンでも最近のものを先に出す。
メンテナーは、Obsidian と Ulysses にあって Aleph にない機能を比べ、これを ADR にするよう求めた（2026-11-07）。
クイックオープン（[ADR 0022](0022-quick-open.md)）は、この履歴を使う。

## 実装すること

- シートを開いたとき（ツリー、検索、診断、クイックオープン、タブの切り替え（[ADR 0024](0024-tabs-and-split.md)）のどれからでも）、そのシートのパスを、ワークスペースごとの最近開いたシートの並びの先頭に置く。すでに並びにあれば先頭へ移す。まとめて開いた章は、開いた章をすべて、右のパネルが従う章を先頭にして置く。
- 並びは、ワークスペースごとに 50 件までとし、`config.json` の `ui` の `recent`（ワークスペースのパスをキーとする）に残す。機械ごとの履歴なので、ワークスペースのファイルには置かない。
- 左のサイドバーの「ブックマーク」のパネル（[ADR 0025](0025-bookmarks.md)）の下に、「最近開いたシート」として新しい順に出す。各行に、シートの名前（`.gm` と `.md` は見出し）と、薄くパスを出し、押すと開く。「消去」で今のワークスペースの並びを空にする。
- ⌘P の入力が空のときは、この並びを出し、入力があるときは、この並びにあるシートに加点する（[ADR 0022](0022-quick-open.md)）。
- 見つからないシート（Aleph の外で消したものなど）は、出すときに飛ばす。並びからは、次に開いたときに書き直す並びで落とす。
- Aleph でファイルの名前を変えたときは、並びのパスも変える。
- 起動したときは、最後に開いていたシート（タブ）を開き直す（[ADR 0024](0024-tabs-and-split.md)）。タブを入れる前は、並びの先頭のシートを開く。

## 実装しないこと

- 最近開いたワークスペースの一覧（ワークスペースは設定の一覧と左上の切り替えで足りる）。
- シートの中の、最近いた行の履歴（戻る、進むの移動）。
- リボンに専用のアイコンを足すこと（ブックマークのパネルに同居させる）。

## テスト設計

DOM に触れない部分を関数に分け、`node --test` で確かめる。テストを先に書いて失敗させてから実装する。

- 並びの更新：先頭に置くこと、すでにあれば先頭へ移すこと、50 件で切ること、まとめて開いた章の置き方、ワークスペースごとに分かれること。
- 読み書き：`ui` の `recent` を読んで書くと同じになること、形の違う値を読み飛ばすこと。
- 名前の変更と消えたファイル：パスが変わること、フォルダの名前の変更でその下が変わること、ツリーにないパスを出すときに飛ばすこと。
- 画面の確かめ方：いくつかのシートを開いてから、ブックマークのパネルの下に新しい順に出ること、⌘P の入力が空のときに同じ順で出ること、消去で空になること、再起動で最後のシートが開くことを確かめる。

## トレードオフ

- 履歴を `config.json` に残すので、機械をまたいでは同じにならない。ブックマーク（[ADR 0025](0025-bookmarks.md)）はワークスペースのファイルに置き、ほかの機械と分け合う。役目を分けて、履歴は機械ごとのものとする。
