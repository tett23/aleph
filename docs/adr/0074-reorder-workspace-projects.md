# ADR 0074: ファイルツリーでプロジェクトを並べ替える

ステータス: 採択

## 文脈

同じ親ディレクトリに複数の作品があるとき、執筆中の作品をほかの作品より上に表示したい。

## 調査した事項

ファイルツリーはディレクトリの階層を保ち、プロジェクトをそのディレクトリの位置に表示する。
同じ親のプロジェクトはディレクトリ名の順に並ぶ。
ワークスペース自体がプロジェクトなら、そのルートを一つのプロジェクトとして表示する。

## 実装すること

プロジェクト行の右クリックメニューに「一つ上へ」「一つ下へ」を加える。
移動先は同じ親ディレクトリにある直前または直後のプロジェクトとし、移動先がある項目だけを表示する。
移動すると二つのプロジェクトの表示位置が入れ替わり、展開中の子の行は親について動く。

## データ構造とアルゴリズム

Aleph の設定ファイル `config.json` の `projectOrder` に、ワークスペースと親ディレクトリの組ごとに、プロジェクトの相対パスを表示順に保存する。
相対パスの起点はワークスペースとする。
保存順がなければ従来の表示順を使う。
保存順があれば、現在も存在するパスを保存順に取り出し、新しく見つかったプロジェクトを従来の表示順で末尾に加える。
この列を、同じ親の子のうちプロジェクトが占めていた位置に順に割り当てる。

## 実装しないこと

ディレクトリの移動、章の並べ替え、別の親に属するプロジェクトどうしの並べ替えは対象外とする。

## 不変条件

1. 一回の操作で隣り合う二つの兄弟プロジェクトだけが入れ替わり、同じ親にある通常のファイルとフォルダは元の位置を保つ。
2. どのプロジェクトも元の親の下に一度だけ現れ、展開状態と選択中のファイルは操作前後で等しい。
3. 同じワークスペースを開き直すと保存順を復元する。別のワークスペースの表示順は変わらない。

| 同じ親の直下にある行 | 操作 | 結果 |
| --- | --- | --- |
| プロジェクトなし | メニューを開く | 移動項目なし |
| ワークスペース自体がプロジェクト | ルートのメニューを開く | 移動項目なし |
| A のみ | A のメニューを開く | 移動項目なし |
| A、通常フォルダ、B | A を一つ下へ | B、通常フォルダ、A |
| B、A | B のメニューを開く | 移動項目は「一つ下へ」のみ |
| B、A | A のメニューを開く | 移動項目は「一つ上へ」のみ |

## テスト設計

テスト名には不変条件の番号を入れる。
不変条件 1 は表の各ケースでメニューの項目と操作後の行順を照合する。
不変条件 2 は「作品集/A」「作品集/B」「草稿/A」があるツリーで、「作品集/A」を展開して子を選択し、「作品集/A」を一つ下へ移す。
移動後の親子関係、展開状態、選択を照合する。
不変条件 3 は二つのワークスペースの一方だけで順序を保存し、両方を開き直して確かめる。
保存後にプロジェクトを一つ削除して別の一つを追加した場合も、残ったプロジェクトの後ろに新しいものが現れることを調べる。

## トレードオフ

右クリックメニューで端まで移動するには、間にあるプロジェクトの数に応じて操作を繰り返す。
パスを識別に使うため、外部で名前を変えたプロジェクトは次に読み込むと新規のものとして扱う。
