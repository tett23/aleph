# ADR 0070: ファイルツリーの右クリックからシートとフォルダの名前を変える

ステータス: 採択

## 文脈

ツリーではシートの行をダブルクリックして名前を変えられる。
右クリックでも同じ操作を選べるようにしたい。
プロジェクトの決まった場所から読むファイルには、どちらの操作でも元の名前が必要になる。

## 実装すること

シートまたはフォルダを右クリックすると、メニューに「名前を変える」を出す。
右クリックした一件の現在の名前を入力欄に出し、確定した名前で同じフォルダ内に改名する。
名前には一つの名前だけを受け付け、パス区切り、`.`、`..` を拒む。
開いているシートの保存、同名のファイルの確認、改名後のエディタやノートの更新には、ダブルクリックと同じ処理を使う。

フォルダを改名すると、中身を階層ごと新しい名前に引き継ぐ。
開いている子孫シートのタブ、編集内容、ノートの対応も新しいパスに引き継ぐ。
プロジェクト行もフォルダとして扱う。
プロジェクトを改名したときはプロジェクト一覧、開いているプロットとその保存先、ノートの保存先も新しいルートに切り替える。
この操作の対象はワークスペース内の項目に限り、登録済みワークスペース自体の移設は扱わない。

プロジェクトのルートを基準に、`plot.csv`、`manifest.toml`、`style.toml` の三つを保護する。
右クリックのメニューから「名前を変える」を外し、ダブルクリックでも改名を始めない。
改名先に同じ三つのパスを指定して既存ファイルを上書きする操作も拒む。
将来スタイルを複数のファイルに分けた場合も、保護するスタイルファイルはルートの `style.toml` に限る。

## 実装しないこと

複数の行の一括改名。
原稿、manifest、プロット内の参照パスの一括更新は別の提案で扱う。

## 不変条件

1. 保護対象のパスでは、右クリックとダブルクリックのどちらからも改名を実行できない。
2. 保護対象以外では、右クリックで改名されるのはメニューを開いた一件だけである。
3. 取消、空の名前、現在と同じ名前、同名の別項目がある場合はディレクトリの内容が変わらない。
4. フォルダの改名後も、すべての子孫のフォルダ内相対パスと開いていたシートの編集内容が保たれる。

| 入力 | 期待する結果 |
| --- | --- |
| プロジェクト直下の plot.csv、manifest.toml、style.toml | 各ファイルで改名不可 |
| draft/style.toml、styles/body.toml | どちらも改名可 |
| 空フォルダ、子と孫があるフォルダ | どちらも改名でき、内部の階層を保つ |
| プロジェクトフォルダ | 直下の三つの保護ファイルは元の名前のまま移る |
| 二件を選び、一方を右クリック | その一件にだけ新しい名前を適用 |
| 既存名を入力、または入力を取消 | 元の名前と内容を保持 |

## テスト設計

テスト名に不変条件の番号を入れる。
条件 1 は三つのパスと同名の下位ファイルについて、メニューの項目とダブルクリック後の入力欄の有無を調べる。
条件 2 は別のタブを開いた状態で右クリックし、対象だけが新しいパスに移ることを調べる。
条件 4 は孫のシートを編集したまま祖先を改名し、同じタブで編集を続け、新しいパスへ保存できることを調べる。
条件 3 は変更前後のファイル名と内容を比較する。

## トレードオフ

保護をプロジェクト相対パスで判定するため、別の場所に置いた同名のシートや分割したスタイルは通常どおり整理できる。
