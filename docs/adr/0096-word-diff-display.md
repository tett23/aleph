# ADR 0096: 差分を文字単位で表示する

Status: proposed

## 文脈

指示者は、差分表示を `diff -word-diff` にすることを求めた（2026-11-22）。
指示者は同日のレビューで、日本語も文字単位で変更箇所が分かるようにすることを指定した。
Git の `--word-diff` を使い、言語によらず文字単位で行内の変更箇所を区別する。
長い段落で一部分を直したときに、行全体の削除と追加だけでは変更箇所を追いにくい。

## 調査した事項

調査したコミットは `8a102bdfa38df9fb2fa7a0852a5ca7da39d186af` である。
[`diffArgs`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/difftab/read.ts#L67) は行単位の `git diff` を呼び、`readDiff` は行頭の `+` と `-` を数える。
[`app/gitpanel.ts`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/gitpanel.ts#L89) も別に `git diff HEAD` を表示する。
[ADR 0088](0088-diff-tab-and-commit-before-applying.md) は、差分タブに表示するファイルと行数の上限を決めている。

ローカルの Git 2.56.0 で、一時ファイルに `red cat` と `blue cat`、`同じ文です` と `違う文です` を置いて比較した。
`git diff --no-index --no-color --no-ext-diff --word-diff=porcelain --word-diff-regex='[^[:space:]]+' -- <変更前> <変更後>` は、英語では red の削除と blue の追加、日本語ではそれぞれの文全体の削除と追加を返した。
改行は `~` の行で表され、差分があるため終了コードは1だった。

同じ Git で `LC_ALL=ja_JP.UTF-8` と `--word-diff-regex=.` を指定して比較した。
`赤い猫です。` から `青い猫です。` は赤の削除と青の追加だけになり、`𠮷と猫` から `𠮷と犬` は猫の削除と犬の追加だけになった。
補助平面の文字 `𠮷` も共通部分に保たれた。
`猫` の末尾の改行だけを削除した場合、porcelain 形式は共通の `猫` と `~` を返し、通常の行差分だけが末尾改行なしの印を返した。

## 実装すること

差分タブと Git パネルのファイル差分を、Git の文字単位の差分で表示する。
取得には `--word-diff=porcelain` を指定し、共通部分、削除部分、追加部分、改行を構造として読み取る。
`--no-color` と `--no-ext-diff` を指定し、外部 diff と色付き出力に表示処理を依存させない。
呼び出しに `--word-diff-regex=.` と UTF-8 のロケールを明示し、改行以外の1文字を比較の単位にする。
利用者の `diff.wordRegex` と属性のドライバーによる単位の変更は受けない。
日本語も英語も同じ規則で比較し、空白を含まない日本語の文でも変更した文字の範囲だけを示す。
ここでの文字は Unicode コードポイントであり、結合文字列や絵文字の書記素クラスタ全体を一単位にはしない。
Unicode 正規化は行わず、元の文字列を保つ。

表示は一つの本文の流れに削除部分と追加部分を並べる。
削除は取消線と削除用の背景色、追加は下線と追加用の背景色で示し、色だけに依存させない。
原稿中の `[-`、`-]`、`{+`、`+}` を差分記号として解釈しない。
本文は必ず HTML としてエスケープする。

比較元の `HEAD`、未追跡ファイル、改名、削除、バイナリの扱いは維持する。
Git パネルで従来から差分本文を取得できない条件（未追跡ファイルやリポジトリ内の下位フォルダをワークスペースとした場合のパスの問題）は、この変更では拡張しない。
行の追加数と削除数は文字単位の差分の行から数えず、同じ比較条件の通常の行差分から求める。
末尾改行の有無も通常の行差分から補い、変更前と変更後のどちらに末尾改行がないかを表示する。
差分タブの上限200ファイルと2,000行は維持し、2,000行は復元した表示上の行（ハンク見出しを含む）に対して数える。
省略件数はその表示行の総数との差にする。

採択時に [ADR 0088](0088-diff-tab-and-commit-before-applying.md) の差分の読み取りと不変条件 I6、I7 の行表現を変更したことを記録する。
実装時に仕様書と README に文字単位の比較と表示を記す。

## 実装しないこと

日本語の形態素解析、言語別の比較単位の切り替え、書記素クラスタ単位の比較、エディタの溝の行変更マークの変更、差分からの編集。

## 不変条件

- I1: 共通、削除、追加、行区切りの表示は、UTF-8 ロケールで `--word-diff-regex=.` を指定して取得した porcelain 形式の各区分に一致し、末尾改行の有無は同じ比較条件の通常の行差分に一致する。
- I2: 原稿の文字列は HTML 要素にも差分制御記号にもならない。
- I3: 追加行数と削除行数は、同じ比較条件の通常の行差分で数えた値に等しい。
- I4: 差分タブは最大200ファイル、各ファイル最大2,000表示行を出し、省略数は表示行の総数との差に等しい。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 差分なし、空ファイル | 変更箇所なし | I1, I3 |
| `red cat` から `bed cat` | r を削除、b を追加、ed cat は共通 | I1 |
| `赤い猫です。` から `青い猫です。` | 赤だけを削除、青だけを追加 | I1 |
| `𠮷と猫` から `𠮷と犬` | 𠮷を壊さず、猫と犬だけを変更表示 | I1 |
| 結合文字と絵文字の変更 | コードポイント単位で比較し、元の文字列を保持 | I1, I2 |
| 改行だけ、末尾改行なし、空白だけの変更 | 改行構造と行数を維持 | I1, I3 |
| `[-x-]`、`{+x+}`、`<script>` | 原稿の文字列として表示 | I2 |
| 2,000行、2,001行 | 後者は1行省略 | I4 |

## 受けいれ条件

- A1: リポジトリのルートをワークスペースとし、既存の両表示で本文を取得できる追跡済みのテキストファイルを開くと、差分タブと Git パネルで同じ変更区分になる。
- A2: 明暗両テーマで削除と追加を区別できる。
- A3: 空白のない日本語の長い段落で1文字だけを置き換えると、その文字だけが削除と追加として表示される。

## テスト設計

小さな一時 Git リポジトリで境界表の変更を作り、porcelain の実出力を取得する。
解析と表示のテストを `ADR 0096 I1: …` の形で先に書き、行単位の現行表示で失敗させる。
I3 と I4 は通常の行差分との比較と上限の前後を検査する。
利用者の `diff.wordRegex`、属性のドライバー、パスに `[` を含む場合も呼び出し条件を確かめる。
A1 から A3 は Tauri で確認する。
UTF-8 ロケールで日本語、補助平面の文字、結合文字、絵文字を比較し、C ロケールを継承したプロセスからでも呼び出し側が UTF-8 を設定することを検査する。

## トレードオフ

日本語の小さな変更を示せる一方、英単語も文字単位に分かれる。
結合文字や絵文字の一部だけに変更の装飾が付く場合がある。
行数集計のために通常の差分も必要となり、Git の呼び出しが増える。
