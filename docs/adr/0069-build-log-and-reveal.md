# ADR 0069: ビルド通知から出力を Finder で表示し、ステータスバーからログを開く

ステータス: 下書き

## 文脈

[ADR 0058](0058-build-from-aleph.md) ではステータスバーの build を押すと問題パネルが開く。
実行したコマンドや出力を確認するには、診断にまとめる前のログが要る。

## 実装すること

手動ビルドの成功通知に「Finder で表示」を置き、そのビルドのプロジェクトの `build/` を [ADR 0053](0053-reveal-in-finder.md) の方法で表示する。
警告だけで成功した場合も同じとする。
失敗通知からは従来どおり問題を確認できる。

ステータスバーの `build 1.0 秒` などの表示を押すと、下部パネルで該当プロジェクトの最新の手動ビルドのログを開く。
ログには実行引数、標準出力、標準エラー出力、終了状態を区別して表示する。
実行中は実行引数と実行中の表示を出し、終了時に結果を反映する。
起動失敗時は理由を残す。
診断は引き続き問題パネルにも出す。

## 実装しないこと

プレビュー用ビルドのログと過去のビルドログの永続化。

## 不変条件

1. 成功通知のボタンはタブを替えた後も通知元の出力先を指す。
2. ステータスバーから開くログは表示対象のプロジェクトの最新の手動ビルドに属する。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 未実行 | build 表示なし |
| 初回を実行中 | build 表示を押すと実行中のログが開く |
| 標準出力が空、標準エラーが JSON 以外 | 空出力を許し、エラーの原文を表示 |
| 二つのプロジェクトで続けて成功 | 各通知がそれぞれの出力先を指す |

## テスト設計

不変条件ごとに番号をテスト名に含め、上表の入力について実装前に失敗を確かめる。
二つのプロジェクトのビルドを逆順に完了させ、通知の操作先と表示したログを検査する。

## トレードオフ

最新の一回に限るため、次のビルド後に前回のログを読み返すことはできない。
