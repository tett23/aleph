# ADR 0024: タブと左右の分割

ステータス: 採択→分割を始める条件とやめる条件は[ADR 0037](0037-split-conditions.md)

## 文脈

Aleph のエディタの枠は、一度に一つのものを出す。
一つのシートか、まとめて開いた複数の章か、プロットである。
画面の状態は、開いているシートの並び `open` と、右のパネルとステータスバーが従うシートの番号 `focus`、プロットを出すプロジェクト `plot` で持つ（[app/store.ts](https://github.com/tett23/aleph/blob/556db161917fdf32808b5b5153fdce0a99c65c71/app/store.ts#L21-L39)）。
ほかのシートを開くと `open` が入れ替わり、前のシートは変更があれば保存され、エディタは作り直されて取り消しの履歴も消える（[app/docs.ts](https://github.com/tett23/aleph/blob/556db161917fdf32808b5b5153fdce0a99c65c71/app/docs.ts#L27-L32)）。
本文と設定集、本文とプロットを行き来しながら書くと、そのたびに開き直すことになる。

Obsidian は、開いたものをタブで並べ、エディタの枠を左右や上下に分けられる。
メンテナーは、Obsidian と Ulysses にあって Aleph にない機能を比べ、これを ADR にするよう求めた（2026-11-07）。

エディタの枠の右には、プレビュー（[ADR 0010](0010-previews.md)）を出せる。
縦書きは、まとめて開いた複数の章でも保つ（[ADR 0019](0019-one-editor-for-both-writing-modes.md)）。

## 実装すること

### 状態

- エディタの枠を、一つか二つの **ペイン** に分ける。ペインは左右に並べる。
- ペインは **タブ** の並びと、選んでいるタブを持つ。
- タブは、今の `open` と `focus` が持つものを一つ持つ。一つのシートか、まとめて開いた複数の章（とそのうちの右のパネルが従う章）か、プロジェクトのプロットである。まとめて開いた章は、章ごとのタブにせず、一つのタブにする（まとめて読み書きするために開いたものなので）。
- 画面の状態の `open`、`focus`、`plot` を、ペインの並び、選んでいるペインの番号、各ペインのタブと選んでいるタブに置き換える。右のパネル、ステータスバー、プレビューは、選んでいるペインの選んでいるタブに従う。
- 同じシートは、すべてのペインとタブを通して一度だけ開く。すでに開いているシートを開こうとしたときは、そのタブとペインを選ぶ。まとめて開いた章の一つを一つのシートとして開こうとしたときも、その章を含むタブを選び、その章に移る。

### 開く、閉じる

- ツリーで押したとき、検索や診断の結果を押したとき、⌘P（[ADR 0022](0022-quick-open.md)）で ↩ を押したときは、今までどおり選んでいるタブの中身を入れ替える。
- ⌥ を押しながらツリーの行を押したとき、⌘P で ⌘↩ を押したとき、タブの並びの「＋」を押したときは、選んでいるペインに新しいタブとして開く（「＋」は ⌘P を出す）。
- ⌘W で選んでいるタブを閉じる。ウインドウのメニューの「ウインドウを閉じる」のキーは ⇧⌘W に変える（[src-tauri/src/lib.rs](https://github.com/tett23/aleph/blob/556db161917fdf32808b5b5153fdce0a99c65c71/src-tauri/src/lib.rs#L340-L350)）。タブの × でも閉じる。
- タブを閉じるときと、ペインを閉じるときは、変更のあるシートを保存する。
- ⌃Tab と ⌃⇧Tab で選んでいるペインのタブを順に移り、⌘1 から ⌘9 でその番号のタブに移る。
- タブはドラッグで並べ替え、ほかのペインへ移せる。

### 分割

- コマンド `view.split`（[ADR 0023](0023-command-palette.md)）で、選んでいるタブを右のペインに移して二つに分ける。右のペインが一つのタブだけを持っていて、それを閉じたときは、分割をやめる。
- ペインを押すと、そのペインを選んだことになる。選んでいるペインのタブの並びに印を付ける。
- 二つのペインの幅は、あいだの境目のドラッグで変え、`config.json` の `ui` に残す。
- 縦と横の切り替えは、今までどおり画面全体に一つとする。縦書きのとき、各ペインの本文の書き方は [ADR 0019](0019-one-editor-for-both-writing-modes.md) に従う（本文でないシートは横書きのまま）。
- プレビューは、今までどおりエディタの枠全体の右に一つ出し、選んでいるペインの選んでいるタブに従う。

### エディタ

- タブを切り替えても、そのタブのエディタは捨てずに隠しておく。カーソル、スクロールの位置、取り消しの履歴を保つ。エディタは表示を仮想化しているので（[ADR 0019](0019-one-editor-for-both-writing-modes.md)）、隠したエディタの重さは描いた行の分にとどまる。
- 開いているタブの並び（各タブのシートのパスかプロットのプロジェクト）、選んでいるタブ、分割を `config.json` の `ui` に残し、次に起動したときに開き直す。開き直せないシート（消したものなど）は飛ばす。

## 実装しないこと

- 同じシートを二つのペインに並べること（同じ文書を二つのエディタで同時に書き換えると、二つの状態がずれるため）。
- 上下の分割と、三つ以上のペイン。
- タブをウインドウの外に出して、別のウインドウにすること。
- ペインごとに縦と横を変えること。
- タブを固定すること（ピン留め）。

## テスト設計

画面の状態の変化（タブとペインの操作）は、今の `reduce` と同じく DOM に触れない関数に書き、`node --test` で確かめる。テストを先に書いて失敗させてから実装する。

- 開く：選んでいるタブを入れ替えること、新しいタブとして開くこと、すでに開いているシートを開くとそのタブとペインを選ぶこと、まとめて開いた章の一つを開くとその章のタブを選んでその章に移ること、プロットをタブとして開くこと。
- 閉じる：タブを閉じたあとに選ぶタブ（右隣、なければ左隣）、最後のタブを閉じると空のペインになること、右のペインの最後のタブを閉じると分割をやめること、閉じるときに保存する対象のシートの一覧を返すこと。
- 移る：⌃Tab と ⌃⇧Tab の巡回、⌘1 から ⌘9（タブの数を超える番号では何もしない）、並べ替え、ほかのペインへの移動（移したタブを選ぶ）。
- 分割：分割したときに選んでいるタブが右へ移ること、選んでいるペインが変わること、右のパネルが従うシートが選んでいるペインのものになること。
- 残すことと戻すこと：タブの並びを `ui` の値に書き、読み戻すと同じ並びになること、開けないシートを飛ばすこと。
- ファイルの名前を変えたとき：すべてのタブの中のパスが変わること。
- 画面の確かめ方：見本のプロジェクトで、章と設定集を二つのタブで行き来してカーソルと取り消しの履歴が保たれること、⌘W と ⇧⌘W がそれぞれタブとウインドウを閉じること、分割して左に本文、右にプロットを出せること、縦書きで分割しても各ペインの章が縦書きのままであること、再起動でタブが戻ることを確かめる。

## トレードオフ

- 画面の状態の中心の `open` を置き換えるので、それを読んでいる部分（右のパネル、ステータスバー、プレビュー、LSP の同期、保存）をすべて直すことになる。直すあいだは、選んでいるタブの中身を今の `open` の形で返す関数を置き、読む側を少しずつ移す。
- 隠したタブのエディタを保つので、タブを多く開くとメモリを使う。
- ⌘W をタブに使うので、ウインドウを閉じるキーが ⇧⌘W に変わる。macOS のほかのアプリのタブ（Safari など）と同じ割り当てである。
