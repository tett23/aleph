# ADR 0005: 画面の構成と見た目

ステータス: 採択

## 文脈

プロトタイプの前に UI のモックアップを描き、メンテナーの意見で何度か描き直した（2026-11-07）。
最初の案は「AI が作ったように見える」と言われ、Obsidian に寄せた案は「Obsidian すぎる」と言われ、Ulysses に寄せた案ではサイドバーが「Ulysses に寄りすぎ」と言われた。
最後に、使いやすさを基準に両者の中間をとった案で落ち着いた（[prototype/mockups/01-write.png](https://github.com/tett23/aleph/blob/64eb1077e2daa4faeec93ae6d0f75528b0c27253/prototype/mockups/01-write.png)）。

プロトタイプを使う中で、配置についても指摘を受けた。

- ツールバーの「縦」「横」と「原稿」「本文」「ページ」は、効く先（左のエディタと右のプレビュー）と逆の位置にあり、見た目と一致していなかった。
- ガントの拡大縮小のボタンがガントから遠く、何に効くのかわからなかった。
- ノートとコミットメッセージの白い枠が、パネルから浮いて見えた。
- アクセントの色が目立ちすぎた。

## 実装すること

### 構成

画面は、左から次の順に並べる。

- **リボン**：細い縦の帯。左のサイドバーに出すものを切り替えるアイコンと、設定を開くアイコンを置く。
- **左のサイドバー**：上にワークスペースの名前を置き、そこからワークスペースを切り替える（[ADR 0004](0004-workspaces-and-projects.md)）。その下に、ファイルのツリー、検索、Git、診断（[ADR 0015](0015-diagnostics-and-search.md)）、共有ライブラリ（[ADR 0014](0014-shared-library-and-assets.md)）のどれかを出す。リボンのアイコンで切り替え、同じアイコンをもう一度押すと畳む。
- **中央**：上にツールバー、その下にエディタとプレビューを左右に並べ、下にステータスバーを置く。
- **右のパネル**：**添付**（シートの目標、キーワード、書くこと、ノート。[ADR 0012](0012-sheet-goals-and-notes.md)）、アウトライン、そのプロジェクトの共有ライブラリを、上のアイコンで切り替える。畳める。

### 操作は効く先の近くに置く

- 操作のボタンは、それが効く部分の近くに置く。ツールバーでは、プレビューを選ぶ「原稿のみ」「本文」「ページ」を右（プレビューの側）に置く。「縦」「横」は原稿の組方向の切り替えで、エディタと本文のプレビューの両方に効く（[ADR 0010](0010-previews.md)）。書き手が切り替えるのは書いている原稿の向きなので、エディタの側の左に置く。
- 部分に固有の操作は、その部分の中に置く（ガントの拡大縮小はガントの右上、ページの拡大縮小とビルドはページの枠の見出し）。

### 見た目

- 外枠は Obsidian に近い構成（リボン、ツリー、設定のダイアログ、ステータスバー）とし、書く部分は Ulysses に近くする（余白のある本文の列、右の目標とノート、ツリーの章に見出しと字数と目標の円）。
- アクセントの色は彩度を落とした黄土色とし、目標の円と、オンのトグルと、選択の文字だけに使う。選択の背景は無彩色とする。
- 入力欄のうちパネルの中に置くもの（ノート、コミットメッセージ）は、枠と白地を持たず、パネルの地にそのまま書く。マウスを乗せたときと書いているときだけ、薄い地を付ける。
- ライトとダークの両方を持ち、既定は OS に合わせる。
- アイコンは線のアイコン（lucide の形）を使う。
- 本文のフォントは明朝、UI は OS のゴシック、コードは等幅とする（[ADR 0006](0006-horizontal-editor.md)）。

### 別ウィンドウ

- ページのプレビュー、本文のプレビュー、プロットは、別のウィンドウに出せる。別ウィンドウはメインのウィンドウとイベントで結果を受け渡す（[ADR 0010](0010-previews.md)、[ADR 0013](0013-plot-and-gantt-chart.md)）。

## 実装しないこと

- テーマの切り替えとカスタムの CSS。ライトとダークだけを持つ。
- タブ。一度に開くのは一つのシートか、まとめて開いた章の並び（[ADR 0006](0006-horizontal-editor.md)）とする。

## テスト設計

見た目と配置は自動テストにしない。
次のことを、ライトとダークのそれぞれで画面を見て確かめる。

- ツールバーの「縦」「横」がエディタの側に、「原稿のみ」「本文」「ページ」がプレビューの側にあること。
- ガントとページの拡大縮小のボタンが、それぞれの枠の中にあること。
- ノートとコミットメッセージが枠を持たず、マウスを乗せたときと書いているときだけ地が付くこと。
- アクセントの色が、目標の円、オンのトグル、選択の文字のほかに使われていないこと。
- 長いパスが設定のダイアログで折り返し、隣の入力欄に重ならないこと。

## トレードオフ

- Obsidian に近い外枠は、Obsidian を使う人には迷わずに使える。その代わり、Ulysses のライブラリとシートの一覧のような、シートを並べて眺める見方は持たない（ツリーに見出しと字数を出すことで代える）。
- タブを持たないので、複数のファイルを行き来するときはツリーか検索を使う。
