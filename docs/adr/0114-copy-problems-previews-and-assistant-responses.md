# ADR 0114: 問題、プレビュー、アシスタントの応答をコピーする

Status: proposed

## 文脈

診断の文言を報告に添えたり、組版後の本文やアシスタントの説明を別の文書に貼り付けたりするときは、画面に出た内容をコピーしたい。
一部を引用するときは文字を範囲選択で取り、一件の応答やプレビューの本文全体が必要なときはボタンで取る。

## 調査した事項

問題のタブでは、診断の行を押した時点で既定のマウス操作を止め、その位置をエディタで開く。
診断の文言からドラッグを始めても、文字の範囲選択を始められない。
[問題のタブのマウス操作](https://github.com/tett23/aleph/blob/fd0067b19dc3d0194220ce1e4892b13ab3e3156d/app/problemsmount.ts#L135-L162)

本文のプレビューは HTML の文章として表示し、CSS で範囲選択を許している。
ページのプレビューは、組版したページを画像として表示する。
[プレビューの描画](https://github.com/tett23/aleph/blob/fd0067b19dc3d0194220ce1e4892b13ab3e3156d/app/preview/render.ts#L41-L64)、[ページ画像の描画](https://github.com/tett23/aleph/blob/fd0067b19dc3d0194220ce1e4892b13ab3e3156d/app/preview/render.ts#L93-L102)、[選択の CSS](https://github.com/tett23/aleph/blob/fd0067b19dc3d0194220ce1e4892b13ab3e3156d/app/style.css#L46-L47)

アシスタントのタブでは、応答欄に説明、差分、検査結果などを表示する。
案を適用するボタンと捨てるボタンがあり、応答をコピーするボタンはない。
[応答欄の描画](https://github.com/tett23/aleph/blob/fd0067b19dc3d0194220ce1e4892b13ab3e3156d/app/assistant/mount.ts#L109-L135)

## 実装すること

### 選択とコピーの操作

診断の文字、プレビューの本文、アシスタントの応答の文字をドラッグで選択し、⌘C でコピーできるようにする。
診断の文字から範囲選択を始めても、エディタを開いたりカーソルを移したりしない。
ファイルを持つ診断の行には「診断の位置へ移動」ボタンを置き、従来の移動操作を割り当てる。
行の位置が無い診断では、ボタンの名前を「診断のファイルを開く」とし、そのファイルを開く。
この決定は [ADR 0055](0055-problems-panel.md) の診断行からファイルへ移る操作を置き換える。

各コピー操作には、マウスで押すか、Tab で焦点を合わせて Enter または Space で押せるボタンを置く。
ボタンの名前で、何がコピーされるかを示す。
ボタンを押すと次の各節で決める単位をプレーンテキストとして macOS の一般のペーストボードへ書く。
⌘C を押したときにこれらの表示領域で文字を選んでいれば、その選択をコピーする。

### 問題のタブ

問題のタブの見出しに「問題をコピー」ボタンを置く。
ボタンは、現在の絞りこみで一覧に出る診断を、スクロール範囲の外にある行も含め、一覧と同じ順でコピーする。
診断がゼロ件ならボタンを無効にする。

コピーするテキストでは、一覧と同じファイルの見出しの下に、そのファイルの診断を並べる。
各診断は、重大度、出どころ、コード、位置、文言の順に、半角空白で区切る。
位置は一覧と同じ `[行, 列]` の形にし、出どころ、コード、位置は値があるものを含める。
文言に含まれる改行を保ち、ファイルのまとまりどうしは空行で区切る。
ファイルを持たない診断には一覧と同じ見出しを使う。

### 本文のプレビュー

プレビューのタブと別ウィンドウの本文の見出しに「本文をコピー」ボタンを置く。
対象は `.gm` と `.md` の本文のプレビューとする。
ボタンは、表示に使っている本文の文字を、スクロール範囲の外にある段落も含めて、文書の順にコピーする。
章をまとめて開いているときは、映している章を順に取り、章どうしを空行で区切る。
段落とコードブロックに含まれる改行を保つ。
折りたたみを閉じている箇所からは、見出しの文字だけをコピーする。
見出しの操作ボタンや組版の状態を知らせる文はコピーに含めない。

プレビューを更新しているあいだに前の本文が画面に残っていれば、その本文をコピーする。
更新が失敗して前の本文が画面に残った場合も、同じ規則を使う。
本文の文字が表示されていない場合はボタンを無効にする。

### アシスタントのタブ

応答ごとに「応答をコピー」ボタンを置く。
ボタンは、その応答に表示している説明、コネクタの切り替えや案を当てられない理由、検査結果、差分を、表示順にコピーする。
差分の `+`、`-`、省略記号と改行を保つ。
頼みの文、モデル名や処理時間、適用と破棄の結果を知らせる文は、応答をコピーする対象から外す。
案を適用した後や捨てた後も、応答欄に残っている文字をコピーできる。
失敗して応答欄に理由を表示した場合は、その理由をコピーする。
応答を待っているあいだと、コピーできる文字が無いときはボタンを出さない。

### ペーストボードへの書き込み

ボタンを押した時点のコピー内容を、文字列を受け取る共通の処理に渡す。
Rust の側では、既存のファイルのコピーと同じく macOS の一般のペーストボードを使う。
書き込みが成功したときは「コピーしました」、失敗したときは「コピーできませんでした」と既存の通知で知らせる。
別ウィンドウでも、そこから同じ書き込みと通知を使えるようにする。

実装時に仕様書と両言語の README に、各ボタンでコピーする単位を書く。

## 実装しないこと

ページのプレビュー、PDF、画像、SVG、Mermaid からの文字の抽出と画像のコピー。装飾つきテキストとしてのコピー。

## 不変条件

- I1: 診断の文字の選択とコピーは、エディタのタブやカーソル位置を変更しない。
- I2: 「問題をコピー」で得た診断の順序と件数は、そのときの絞りこみを適用した一覧と等しい。
- I3: 「本文をコピー」で得た文字は、押した時点で表示している本文に属し、表示上の章の順序と章内の文書順を保つ。
- I4: 「応答をコピー」で得た文字とその順序は、押したボタンと同じ応答欄のうち、コピーの対象として定めた箇所と等しい。
- I5: ボタンによるコピー一回につき、そのときの文字を一回書き、書き込み結果に合う通知を一つ出す。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 診断の文言の途中からドラッグして ⌘C | 選んだ文字が貼り付けられ、エディタの位置は変わらない | I1 |
| エラー一件と警告一件の一覧で、警告だけに絞る | 警告一件だけをファイルの見出しつきでコピーする | I2 |
| 絞りこんだ結果がゼロ件 | ボタンは無効で、ペーストボードへの書き込みはゼロ回 | I2 |
| 二章を映す本文の更新中に押す | 画面に残る二章の本文をその順でコピーする | I3 |
| 二つの応答があり、先の応答で案を捨てた後にコピーする | 先の応答欄に残る説明などだけをコピーする | I4 |
| 応答待ち、または応答が失敗して理由が出た状態 | 待機中はボタンが無く、失敗時は理由をコピーする | I4 |
| 書き込みが成功する場合と失敗する場合 | 一回だけ書き込みを試し、その結果を一つ知らせる | I5 |

## 受けいれ条件

- A1: 問題のタブで診断の一部を選んで ⌘C でコピーできる。「問題をコピー」では絞りこんだ一覧をコピーし、「診断の位置へ移動」ではその位置を開ける。
- A2: 本文のプレビューのタブと別ウィンドウで、範囲選択とボタンの両方からコピーできる。二章をまとめて映したときは、ボタンで両方の本文をコピーできる。
- A3: アシスタントのタブで説明の一部を選んでコピーできる。二つの応答を表示したときは、各ボタンから対応する応答をコピーできる。

## テスト設計

問題の一覧とアシスタントの応答を文字列にする処理をテストする。
診断の絞りこみ、結果が空のとき、出どころや位置の有無、複数行の文言、応答の適用と破棄の前後を入力にする。
ペーストボードへの書き込みを差し替え、呼び出しの回数と通知の内容を照合する。
テスト名には `ADR 0114 I2: ` のように ADR と不変条件の番号を付ける。

A1 から A3 と I1、I3 は、Tauri のデバッグ版の WKWebView で確かめる。
ドラッグによる選択、⌘C、ボタンのキーボード操作を試し、別のテキストエディタへ貼り付けて結果を見る。
本文は横書きと縦書きで確かめ、折りたたみの開閉、コードブロック、組版中と失敗時に残した前の本文も試す。

## トレードオフ

診断の文言を選択できるようにすると、文言を押して診断の位置へ移る操作には別の押し先が要る。
行に移動ボタンを置けば、どこから文字を選び、どこを押せばファイルを開けるかが決まる。
コピーした内容は、プレーンテキストを扱う貼り付け先でも使える。
