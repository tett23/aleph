# ADR 0053: ツリーの行とタブの右クリックから Finder で表示する

ステータス: 採択

## 文脈

原稿の画像やフォントを足すとき、書き手はファイルを Finder で扱うことがある。
今の Aleph には、ツリーやタブのファイルを Finder で表示する方法がない。
書き手は Finder の側でワークスペースからフォルダをたどり直すことになる。

ツリーの行には右クリックのメニューがある（[app/ui/tree.ts](https://github.com/tett23/aleph/blob/eed8f42/app/ui/tree.ts#L245)）。
ほかの部分は、`treeMenus` に項目を足す（「ゴミ箱に移す」、ブックマーク）。
プロジェクトの行もフォルダの行（`data-dir`）なので、このメニューの対象に入る。
タブ（[app/editor/panes.ts](https://github.com/tett23/aleph/blob/eed8f42/app/editor/panes.ts#L91)）には、右クリックのメニューがない。

[ADR 0042](0042-ipc-trust-boundary.md) により、画面から Rust に渡すパスは、ワークスペースなどの範囲の中に限る。
外のプログラムは、Rust の側が決めたものだけを動かす。

## 実装すること

- Rust に、パスを一つ受け取り、Finder でそれを選んだ状態で表示するコマンド `reveal_path` を足す。
  - パスは読み取りの範囲（`may(..., Read)`）で確かめる。範囲の外なら誤りを返す。
  - 確かめたあとの絶対パスを、`/usr/bin/open -R` に渡す。画面から実行ファイルや引数は渡せない。
- ツリーの行の右クリックのメニューに「Finder で表示」を足す。ファイル、フォルダ、プロジェクトの行のどれでも出す。
- タブに右クリックのメニューを付け、「Finder で表示」を出す。
  - シートのタブでは、そのタブで焦点のあるシートを表示する（章を並べたタブでは、焦点のある章）。
  - プロットのタブでは、プロジェクトの `plot.csv` を表示する。
  - 何も開いていないタブでは、メニューを出さない。
- 仕様書のツリーとタブの節に書く。

## 実装しないこと

- Finder 以外のアプリで開くこと（「ほかのアプリで開く」など）。
- ターミナルで開くこと、パスをコピーすること。
- ツリーのプロットの行（`data-plot`）への追加。今の右クリックのメニューの対象から外れているので、そのままにする。
- macOS 以外への対応。Aleph はまず Apple シリコンの macOS を対象にしている。

## テスト設計

`node --test` と `cargo test` で、テストを先に書いて失敗させてから実装する。

- Rust：`open` に渡す引数を作る関数が、`["-R", <絶対パス>]` を返すこと。範囲の外のパスでは、引数を作る前に誤りになること（[ADR 0042](0042-ipc-trust-boundary.md) の範囲の確かめを通ること）。
- 画面：タブから表示するパスを決める関数が、シートのタブでは焦点のあるシートを、プロットのタブでは `plot.csv` を、空のタブでは何も返さないこと。
- 画面：ツリーのメニューに足す関数が、ファイルとフォルダのどちらでも「Finder で表示」を返すこと。
- 画面の確かめ方：試験のワークスペースで、ファイル、フォルダ、プロジェクトの行とシートとプロットのタブを右クリックし、Finder でそのファイルが選ばれた状態で開くことを確かめる。

## トレードオフ

- `open -R` は Finder を前に出す。書き手が頼んだ操作なので、そのままにする。
- 範囲の確かめは読み取りとする。Finder で表示するだけで、Aleph は何も書かないからだ。
