# ADR 0079: 保存したときにシートの見出しを読み直す

Status: accepted

## 文脈

サイドバーのファイルツリー (以下、ツリー) は、`.gm` と `.md` のシートの最初の見出しを、その行の名前として出す ([ADR 0004](0004-workspaces-and-projects.md))。
しかし今は、見出しを書き換えて保存しても、行の名前は変わらない。
名前が変わるのは、後でツリー全体を読み直したときである。

この遅れのため、書き手は名前の変化を、見出しを書き換えた操作と結びつけられない。
実際に、見出しが `# 章構成` の `節構成.md` を開いたまま、右クリックでシートを追加したとき、行の名前が「節構成」から「章構成」に変わった。
書き手はこれを、開いていたファイルがツリーから消えたと受けとった。
この ADR は、保存したときに、そのシートの見出しを読み直すことを決める。

## 調査した事項

この節には、ソースで確かめたことだけを書く。

シートの名前は、一つの表 `ctx.titles` (パスから名前への表) にある。
この表に書くのは、ツリー全体を読み直す `reloadTree` だけである ([tree.ts:66-74](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/ui/tree.ts#L66-L74))。
`reloadTree` は、ワークスペースの `.gm` と `.md` をすべて読み、最初の見出しがあれば表に書き、無ければ表から消す。

表を読むのは、ツリーのほかに次の箇所である。

- ツールバーの題 ([shell.ts:139-143](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/ui/shell.ts#L139-L143))
- 分割したエディタの見出し ([panes.ts:31](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/editor/panes.ts#L31))
- ブックマーク、最近のシート、キーワード、リンクのパネル
- 埋め込みの枠の見出し ([ADR 0039](0039-embed-frame-titles.md))
- クイックオープンと、LSP に渡すシートの一覧 ([quickopen.ts:37-41](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/quickopen.ts#L37-L41))

`reloadTree` は、読み直した後に `treeReloaded` の処理を走らせる。
そこには、ウィキリンクの索引の作り直し ([wikilinkmount.ts:164](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/wikilinkmount.ts#L164)) と、LSP へのシートの一覧の送り直し ([lsp/mount.ts:308](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/lsp/mount.ts#L308)) がある。

保存は、書いた後にストアに `saved` の操作を送る ([docs.ts:42-53](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/docs.ts#L42-L53))。
`saved` は、そのシートの `saved` (ディスクにある中身) を書いた中身に変える ([store.ts:276-277](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/store.ts#L276-L277))。
`saved` は、外で変わった中身を取りこんだとき ([watchmount.ts:41-46](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/watchmount.ts#L41-L46)) と、整形の後 ([lsp/mount.ts:218-227](https://github.com/tett23/aleph/blob/0966994371f0b672f1be72231b7ce372859dbceb/app/lsp/mount.ts#L218-L227)) にも送られる。
`saved` は、`manifest.toml` を書き換えたときにも送られるが、これは見出しを持たない種類である。

## 実装すること

ストアの `saved` で、開いているシートの `saved` が変わったら、そのシートの名前を読み直す。
名前は、`reloadTree` と同じ関数 (`titleOf`) で、`saved` の中身から求める。
求めた名前があれば表に書き、無ければ表から消す。
ディスクを読み直さず、`saved` の中身を使う。

名前が前と変わったときだけ、次を行う。

- ツリーとツールバーを描き直す。
- `treeReloaded` の処理を走らせ、ウィキリンクの索引と LSP のシートの一覧を新しい名前にする。

名前が変わらないときは、何も描き直さない。
保存のたびに描き直すと、設定の `autosaveSeconds` の間隔での自動保存のたびにツリーが描き直されるからである。

保存していない書き換えでは、名前を変えない。
ツリーの名前は、ディスクにある中身の見出しとする。

## 実装しないこと

- 入力のたびに名前を変えること。
- 開いていないシートの名前を、保存のほかの契機で読み直すこと。外で変わったシートは、今までどおり監視によるツリーの読み直しで変わる。
- 名前が変わったことを書き手に知らせること。
- ツリーの行の名前の出し方 (見出しとファイル名の並べ方) を変えること。

## 不変条件

- I1: `saved` の後、そのシートの表の名前は、`titleOf(シートの種類, saved の中身)` が null でなければその値に等しく、null なら表に無い。
- I2: `saved` の後、ほかのシートの表の名前は変わらない。
- I3: `treeReloaded` の処理とツリーの描き直しは、`saved` で名前が変わったときに一度ずつ走り、変わらないときは走らない。
- I4: 保存していない書き換えでは、表の名前は変わらない。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| `# 節構成` を `# 章構成` に書き換えて保存 | 名前は「章構成」、描き直しと処理が一度ずつ | I1, I3 |
| 見出しを消して保存 | 表に無く、行はファイル名になる | I1, I3 |
| 見出しの無いシートに `# 一` を書いて保存 | 名前は「一」 | I1, I3 |
| 見出しの後の本文だけを書き換えて保存 | 名前は同じで、描き直さない | I1, I3 |
| 中身の同じまま保存 | 描き直さない | I3 |
| 空のシートを保存 | 表に無い | I1 |
| `# 章構成` に書き換えたが保存していない | 名前は前のまま | I4 |
| 二つのシートを開き、片方だけを保存 | もう片方の名前は変わらない | I2 |
| `manifest.toml` の `saved` | 表は変わらない | I2 |
| 外で変わった中身を取りこんだ `saved` | 取りこんだ中身の見出しになる | I1 |

## 受けいれ条件

- A1: シートの見出しを書き換えて保存すると、ツリーの行の名前とツールバーの題が、そのときに新しい見出しになる。
- A2: 見出しを書き換えて保存した後に、ほかのシートのウィキリンクの補完に、新しい名前が出る。

## テスト設計

- 名前を読み直す処理を、ストアと表を受けとる関数として切り出し、境界の表の各行を `ADR 0079 I1: …` などの名前のテストで確かめる。
- I3 は、描き直しと `treeReloaded` の代わりに、呼ばれた回数を数える関数を渡して確かめる。
- A1 と A2 は、デバッグ版の試験のワークスペースで、手で確かめる。

## トレードオフ

ディスクを読まずに `saved` の中身を使うと、保存の直後に外で書き換えられたときに、ディスクと名前が一時的に食い違う。
しかし外での書き換えは監視がツリーを読み直すので、そのときに名前もディスクに合う。
保存のたびにディスクを読み直すより、読むファイルが無い分だけ軽い。

入力のたびに名前を変えれば、書き手は名前の変化をもっと早く見る。
しかし見出しを打っている途中の文字で、ツリーの行の名前が何度も変わる。
ツリーの名前はディスクの中身に合わせ、保存で変える方を選ぶ。
