# ADR 0067: ファイルツリーに実際の階層を表示し、表示対象を設定で選ぶ

ステータス: 採択（未実装）

## 文脈

現在のツリーは登録済みの章をプロジェクト直下に集めるため、`chapters/part/a.gm` の実際の置き場所が分かりにくい。

## 実装すること

章を実際の親の下に一度だけ表示する。
`chapters` も通常のフォルダとして展開、折り畳みの対象にする。
同じ親の登録済みの章は manifest 順で先に並べ、プロジェクト直下ではその次に `plot.csv` を置く。
残りの項目は従来順で置く。

設定に「隠しファイルを表示」（既定オフ）と「.gitignore 対象のファイルを表示」（既定オン）を置く。
前者は名前が `.` で始まるファイルとフォルダ、後者はワークスペース内の各 `.gitignore` に従って除外される項目に適用する。
配下の規則、ディレクトリ指定、否定パターンは Git の照合規則に従う。
両方に該当する項目は両方がオンのときだけ表示する。

設定を `config.json` に保存して変更を直ちにツリーに反映する。
キーが欠けているか真偽値以外なら各既定値を用いる。
非対応形式、シンボリックリンク、深さ上限、`build/`、`node_modules/`、`target/`、`dist/` の既存の除外は引き続き適用する。
表示設定は検索やプロジェクトの判定から独立させる。

## 実装しないこと

検索範囲やビルドの章順の変更。

## 不変条件

1. 表示対象の gm の親は実際の親と一致し、祖先をすべて展開すると一行だけ現れる。
2. 固定の除外に該当しない項目は、自身と全祖先が二つの表示条件を満たすときだけ展開したツリーに現れる。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 空の chapters、登録章だけの chapters | どちらもフォルダ行を表示 |
| 隠しかつ ignore 対象の .draft.md | オンとオンの組合せだけで表示 |
| 通常名の ignore 対象、ignore 対象の表示をオフ | 非表示 |
| 設定キーがない旧版、または値が不正 | 隠しファイルは非表示、通常名の ignore 対象は表示 |

## テスト設計

不変条件ごとに番号をテスト名に含め、上表の入力について実装前に失敗を確かめる。
隠し名と ignore の該当有無を独立に変え、設定の四通りで表示パスと深さを比較する。

## トレードオフ

複数のフォルダに分けた原稿では、章の全体を読むために複数の行を展開する必要がある。
