# ADR 0014: 共有ライブラリと画像のアセット

ステータス: 採択

## 文脈

メンテナーは、フォントを共有フォルダからコピーするようにと求めた。
続けて、プラグインと関数も複数のプロジェクトにまたがって管理できるようにと求め、ドラッグアンドドロップでフォルダにコピーするようにと求めた。
さらに、フォント、プラグイン、関数をサイドバーの項目にし、すべてのプロジェクトを横断して管理できるようにと求めた。
画像をアセットとして入れられるようにとも求めた（2026-11-07）。

Golem の側では、次のことが決まっている。

- `golem new` はフォントを取得してプロジェクトの `fonts/` に置く。`--no-fonts` を付けると取得しない。
- プラグインは、`manifest.toml` の `[plugins.<名前>]` に `path = "plugins/<名前>.wasm"` と書けば、プロジェクトの中の `.wasm` を使える。`path` のプラグインは `plugins.lock` に入らず、リポジトリの版管理で固定される。
- `.gm` は `@import functions/<名前>.emet as <名前>` で `.emet` の関数を使う。
- 図版は `@figure パス alt="…"` で書き、続く字下げした行がキャプションになる。画像は PDF、SVG、PNG、JPEG である。

## 実装すること

### 共有ライブラリ

- **共有ライブラリ** は、設定で決めた一つのフォルダである。中に `fonts/`、`plugins/`（`.wasm`）、`functions/`（`.emet`）を置く。設定の画面から作れる。
- プロジェクトには、共有ライブラリのファイルをコピーして入れる。参照（シンボリックリンク）にしない。プロジェクトのリポジトリが、使っているフォント、プラグイン、関数の版を固定するためである。
- **フォント**：プロジェクトを開いたとき、`style.toml` が指すフォントのうちプロジェクトにないものを、共有ライブラリから同じ名前のものを探してコピーする。ライセンスのファイル（`LICENSE` で始まるもの）も一緒にコピーする。新しいプロジェクトは `golem new --no-fonts` で作り、フォントは共有ライブラリからコピーする（[ADR 0004](0004-workspaces-and-projects.md)）。
- **プラグイン**：入れると、`plugins/` にコピーし、`manifest.toml` に `[plugins.<名前>]` と `path` の宣言がなければ足す。
- **関数**：入れると、`functions/` にコピーする。`.gm` への `@import` は書き手が書く。

### 横断の管理

- 左のサイドバーの「共有ライブラリ」に、共有ライブラリのフォント、プラグイン、関数のそれぞれについて、すべてのワークスペースのすべてのプロジェクトでの状態を出す。状態は、同じものが入っている、中身が違う、入っていない、の三つとする。
- 中身が違うとき、どちらが新しいかは判断しない（プロジェクトの側で手を入れた場合もありうる）。
- プロジェクトの名前を押すとそのプロジェクトに入れ、「すべてに入れる」ですべてのプロジェクトに入れる。中身が違うプロジェクトに入れるときは、上書きすることを確かめてから入れる。上書きしたファイルは Git で戻せる（[ADR 0011](0011-saving-and-git.md)）。
- 右のパネルの「共有ライブラリ」には、開いているプロジェクトでの状態だけを出す。
- 中身が同じかは、バイトの列で比べる。

### ドロップ

- 共有ライブラリのパネル（左と右）にファイルを落とすと、拡張子で振り分けて共有ライブラリにコピーする（`.wasm` は `plugins/`、`.emet` は `functions/`、フォントとライセンスは `fonts/`）。扱えないファイルは通知で知らせる。

### 画像のアセット

- 画像はプロジェクトの `images/` に置く。
- `.gm` のエディタに画像（PNG、JPEG、SVG、PDF）を落とすと、`images/` にコピーし、落とした行の後に `@figure images/<名前> alt="<名前>"` と、字下げしたキャプションの行を差し込む。
- ツリーのフォルダに落とすと、そのフォルダにコピーする。
- 同じ名前のファイルがあれば、名前の後ろに `-2`、`-3` と付けて、上書きしない。
- ツリーに画像を出し、開くと表示する（[ADR 0010](0010-previews.md)）。

## 実装しないこと

- プラグインの配布の機構（URL からの取得、`plugins.lock`）。Golem の `golem plugin` に任せる。
- プロジェクトから共有ライブラリを消す操作。消すときは Finder か Git で行う。
- 画像の加工（縮小、形式の変換）。

## テスト設計

- 状態の判定：同じ、中身が違う、ない、の各場合を、一時ディレクトリで `node --test` で確かめる。
- プラグインを入れる：`manifest.toml` に宣言がない場合、すでにある場合、末尾に改行がない場合で、足した結果を確かめる。
- フォントのコピー：`style.toml` が指すフォントのうち、ないものだけがコピーされること、ライセンスもコピーされることを確かめる。
- 名前の衝突：同じ名前のファイルが 0、1、2 個ある場合の名前を確かめる。
- `@figure` の差し込み：空の行、文字のある行、文書の末尾に落とした場合の結果を確かめる。
- 画面の確かめ方：Finder から共有ライブラリのパネルに `.wasm` を落とすとコピーされること。エディタに画像を落とすと `images/` にコピーされ、`@figure` が入ること。「すべてに入れる」で全プロジェクトに入ること。

## トレードオフ

- コピーにすると、プロジェクトごとに版が固定され、共有ライブラリを変えても既存のプロジェクトが壊れない。その代わり、入れ直しは横断の管理の画面から明示的に行う必要がある。
- `@import` を自動で書かないので、関数を入れても原稿は変わらない。使うときに書き手が書く。
