# ADR 0090: エディタの折り返しに禁則とぶら下げ組を反映する

Status: proposed

## 文脈

指示者は、ぶら下げ組を指定した原稿はエディタ上でもぶら下げ、禁則設定を守ることを求めた（2026-11-22）。
ここでのぶら下げ組は、行末の句読点を行の外へ出す組み方を指す。
段落の字下げとは区別する。

## 調査した事項

Aleph の調査対象は `8a102bdfa38df9fb2fa7a0852a5ca7da39d186af` で、2026-11-22 の `git ls-remote origin HEAD` と一致した。
エディタは [`app/style.css`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/style.css#L143) の `white-space: pre-wrap`、`overflow-wrap: break-word`、`word-break: normal` で折り返す。
[`app/ed/view.ts`](https://github.com/tett23/aleph/blob/8a102bdfa38df9fb2fa7a0852a5ca7da39d186af/app/ed/view.ts#L88) は字詰めを `--chars` に渡す。
`app` 内を `kinsoku`、`hanging-punctuation`、禁則、ぶら下げで検索したが、エディタに組版設定を渡す処理は見つからなかった。

ローカルの Golem `dc8bf92ec33549ae2cd3b1cbf43487d451b1071a` の [`Style.hs`](https://github.com/tett23/golem/blob/dc8bf92ec33549ae2cd3b1cbf43487d451b1071a/modules/golem-project/src/Golem/Project/Style.hs#L2147) は `composition.kinsoku` と `composition.hanging-punctuation` を読む。
`kinsoku` の選択肢は `strict` と `loose` である（同ファイルの `kinsokuValues`）。
WebKit で各設定を満たせるかの実機検証はまだ行っていない。

## 実装すること

プロジェクトに属する `.gm` のエディタは、Golem が解決した有効な禁則とぶら下げ組の設定を使う。
設定の省略時は Golem の既定値に従う。
独立した `.gm` と `.md`、`.txt` は Golem の既定の禁則とぶら下げ設定を使う。
コードや設定ファイルのエディタには適用しない。
プロジェクトの `style.toml` の保存後には設定を読み直し、開いている対象シートに反映する。
不正な設定はエラーを知らせ、最後に読み込めた値を保つ。
読み込めた値が無い場合は既定値を使う。

横書きと縦書きの両方で、折り返し候補を有効な禁則に従って選ぶ。
ぶら下げを有効にした場合、Golem の規則でぶら下げ可能な句読点が行末にあるときは、行の外に表示できる余白を確保する。
対象は原稿の文字列の表示であり、命令を評価したページの再現ではない。
エディタで解釈していない段落別の組版指定は、ページプレビューで確認する。

Golem の設定解決や禁則の文字集合を Aleph に複製しない。
実装前に Golem の既存の呼び出し口と WebKit の描画を検証し、設定値から表示への対応を固定する。
CSS で規則を満たせず Golem 側の機能追加が必要な場合は、その変更の ADR を先に用意する。
ブラウザの既定の禁則で代用して実装済みとはしない。

[ADR 0019](0019-one-editor-for-both-writing-modes.md) の描画の決定を補足する。
実装時に仕様書と README のエディタの説明を更新する。

## 実装しないこと

ページとの行分割の完全一致、改ページ見積もりの精密化、組版アルゴリズムの Aleph 内での再実装。

## 不変条件

- I1: 対象シートに適用する禁則とぶら下げの値は、読み込みに成功した最新の有効値（未取得なら既定値）に等しい。
- I2: 自動折り返しは有効な禁則で禁止された文字間には置かず、許される候補が無いときは文字を欠落させず行からあふれさせる。
- I3: ぶら下げが無効なら句読点をぶら下げず、有効なら規則に該当する行末句読点をぶら下げる。
- I4: 設定変更と折り返しによって文書の文字列、選択の UTF-16 位置、取り消し履歴は変わらない。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 空、1文字 | 欠落も不要な折り返しも無い | I2, I4 |
| ちょうど収まる本文の直後に句点 | 有効時はぶら下げ、無効時は禁則に従う | I2, I3 |
| 行頭に来る閉じ括弧、行末に来る開き括弧 | 禁止された位置では折り返さない | I2 |
| strict と loose で扱いが異なる文字 | Golem の分類に一致 | I1, I2 |
| 設定変更、構文不正 | 成功時だけ値を更新し、本文は保持 | I1, I4 |

## 受けいれ条件

- A1: 同じ原稿を縦書きと横書きで開き、禁則とぶら下げ設定を切り替えると境界表の表示になる。
- A2: 折り返し付近で選択、コピー、IME 入力、取り消しができ、ぶら下げた文字も選択できる。

## テスト設計

設定解決の受け渡しと折り返し規則のテストを `ADR 0090 I1: …` の形で先に書き、現行実装で失敗させる。
I2 と I3 の期待値は Golem の規則から取得し、両組み方向で境界表を検査する。
I4 は設定変更前後の文書、選択、履歴を比較する。
A1 と A2 は Tauri の WebKit で、画面幅を1文字分増減して確認する。
自動テストで CSS の計算値を確認するだけでは完了としない。

## トレードオフ

原稿とページで禁則の設定はそろうが、原稿には命令の文字も見えるため行分割は一致しない。
Golem の解決結果を使うことで設定の二重管理を避けられる一方、実装には呼び出し口の検証が必要になる。
