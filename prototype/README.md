# Aleph のプロトタイプ

捨てる前提のプロトタイプ。
使ってみてから ADR とロードマップを書く。
ここのコードは ADR を経ていない。

## 動かし方

```sh
npm install
npm run tauri dev
```

.app にするには `npx tauri build --debug --bundles app`。
golem と shem を同梱するには、先に `scripts/bundle-tools.sh` を実行する（`src-tauri/resources/` にコピーする）。

## 構成

- `mockups/` UI のモックアップ（HTML と、headless Chrome で撮った PNG）
- `icon/aleph.svg` アイコン（ℵ はヒラギノ明朝 W6 の輪郭をパスにしたもの）
- `src-tauri/` Rust の側。ファイル、検索（ripgrep の ignore と regex）、git の実行、golem と shem の実行、`golem lsp` との橋渡し、ウィンドウの位置と大きさの記録
- `src/` TypeScript の側（クラスなし）。CodeMirror 6 のエディタ、ツリー、プレビュー、プロット、パネル
- `plugins-example/` Aleph のプラグインの見本

## できること

- ワークスペースは Git のリポジトリ一つ。プロジェクト（`manifest.toml` のあるディレクトリ）をサブディレクトリに置く。複数のワークスペースを一つのウィンドウで切り替える
- ツリーに章の見出し、字数、目標の円、未コミットの印を出す。章は manifest の順
- エディタ：行番号の左に HEAD からの変更の印、LSP（診断は行番号の右の印と波線、ステータスバーのエラーの数を押すと一覧。ホバー、補完、整形）、改ページの見積もりの印、1 行の字数での折り返し、行間と不可視文字の設定
- 保存：変更があれば 10 秒ごと（設定で変えられる。変えた値は次の起動から効く）。⌘S で LSP の整形をしてから保存する（設定で切れる。自動保存では整形しない）。⌥⇧F で整形だけする
- コミット：ワークスペースごとに 1 日 1 回、変更があれば `Autosave 日付` で自動コミットする（起動時と 1 時間ごとに確かめる。設定で切れる）。手動では Git のパネル、「…」の「今すぐコミット」、⌘⇧K
- 縦書きと横書き。縦書きのエディタは textarea の裏に同じ字詰めの影の層を置き、各行の上に行番号と差分の印を出す（色付けはない）
- フォント：本文（gm、md、txt）は明朝、それ以外（toml、emet、csv、svg、mermaid など）は等幅。gm の中でも、命令の頭と引数、式の中身は等幅にし、散文スロットは本文のまま
- 本文のプレビュー：`golem build --target html` の結果。命令と式の記号は消え、結果（式の値、ルビ、関数の出力）は反映される。組めないときは記号を除いただけの本文を出す
- ページのプレビュー：`golem build --target pdf` のあと `shem render` で PNG にする。拡大縮小できる（ボタン、ピンチ、⌘ とスクロール。100% は枠の幅）。解像度は既定で自動にし、枠の幅、画面の倍率、拡大率、style.toml の判型から dpi を決める。拡大して足りなくなったら shem だけで描き直す。別ウィンドウにもできる
- md、gm、emet、csv、tsv、toml、svg、pdf、mermaid（.mmd）と画像（png、jpg、gif、webp）を開く。md は gm に変換できる
- 画像のアセット：gm のエディタに画像を落とすと、プロジェクトの `images/` にコピーし、落とした行の後に `@figure images/名前 alt="…"` とキャプションの行を差し込む（PNG、JPEG、SVG、PDF）。ツリーのフォルダに落とすと、そのフォルダにコピーする。同じ名前があれば `-2` などを付ける
- 複数の章：ツリーで gm を選んだあと、shift を押しながら別の gm を押すとその間の章を、⌘ を押しながら押すとその章を足し引きして、まとめて開く。エディタは章ごとに縦に並び、本文のプレビューも選んだ章を並べる。エディタは横書きだけ
- 右のパネル：目標（手で決めるか、プロットの予定字数）、キーワード、書くこと（チェックできる）、プロットのメモと断片、ノート（シートごとに1つ、パネルの残りを埋める。`.aleph/notes.json`）、アウトライン、共有ライブラリ
- プロット：`plot.csv` を表で編集し、開始と終了の列からサブプロットごとのガントチャートを描く。任意の列を「＋列」で足せる（見出しの × で消す。plot.csv の見出しにそのまま入る）。ガントは拡大縮小できる（ボタン、ピンチ、⌘ とスクロール）。開始と終了は任意の文字列（「帝国暦302年・春」など）でよく、ガントの軸の並び（暦）は `plot-calendar.txt` に 1 行 1 つ書く（ガントの「暦」で編集できる）。暦がなければ、すべて数か日付なら値の順、そうでなければ表に出てくる順。別ウィンドウにもできる
- 診断：左のリボンのチェックリストのアイコンで、プロジェクトを選んで golem check、lint、preflight を実行し、結果をファイルごとに一覧する。項目を押すとその行を開く
- 検索：このプロジェクト、ワークスペース、すべて。正規表現と大文字小文字の区別
- Git：変更の一覧、差分、コミット、push、pull、履歴
- 共有ライブラリ：左のリボンの本棚のアイコンで、フォント、プラグイン、関数のそれぞれが、すべてのワークスペースのすべてのプロジェクトに入っているか（同じか、ライブラリの方が新しいか、ないか）を一覧し、プロジェクトごとか「すべてに入れる」で入れる・更新する。`fonts/`、`plugins/*.wasm`、`functions/*.emet` を置くフォルダ。右の「共有ライブラリ」のパネルにファイルをドロップすると、種類ごとにこのフォルダへコピーする。フォントは開いたときに自動で、プラグインと関数は「入れる」でプロジェクトにコピーする。プラグインは manifest に `path` の宣言を足す。ライブラリ側が変わったら「更新」を出す
- 設定：本文とコードの文字サイズ、Golem と shem のバイナリ（空なら同梱、`~/.local/bin`、PATH の順）、共有ライブラリ、行間、1 行の字数、原稿用紙、不可視文字、外観、ワークスペース
- ウィンドウの位置と大きさを記録し、起動時に戻す。どのディスプレイにも収まらなければ既定の大きさで中央に置く

## 確かめていないこと

- エディタへのキー入力（10 秒ごとの自動保存、差分の印の更新、LSP の補完）。確認に使ったツールからキー入力を送れなかった
- ウィンドウを手で動かしたときの記録（記録ファイルを手で書いて、復元と、画面の外なら既定に戻ることは確かめた）
- md → gm の変換、Mermaid と SVG のプレビュー、別ウィンドウ、Aleph のプラグインの読み込み
- 共有ライブラリのプラグイン（.wasm）を入れたあとのビルド
- 共有ライブラリと画像のドロップ（Finder からドラッグする操作を送れなかった）
- shift と ⌘ を押しながらのクリックによる複数の章の選択（修飾キー付きのクリックを送れなかった）

## わかったこと（ADR に持ちこむ候補）

- golem check と lint は JSON を標準出力に、preflight は標準エラー出力に書く
- golem lsp は manifest の章に載ったファイルにだけ診断を返す。URI はパーセントエンコードしたものでないと、日本語のパスのファイルを見つけない。位置は UTF-16

- CodeMirror 6 は縦書きを扱えない。縦書きの編集には別の仕組みが要る
- 改ページの位置は見積もりにすぎない。Golem から行と改ページの対応を受け取れれば正確になる
- 本文のプレビューは HTML のビルドで 0.2 秒ほど。保存のたびに組んでよい
- 「一覧」の列の意味が決まっていないので、プロットの列に入れていない
- 縦書きの影の層は、テキストエリアと同じ字詰めになることに頼っている。字の大きさが混ざる色付け（等幅の命令など）は縦書きではできない
