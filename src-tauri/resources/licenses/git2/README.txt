Aleph includes Git support through git2 0.21.0 and libgit2 1.9.7.
The MIT and Apache-2.0 license texts cover git2, libgit2-sys, libssh2-sys,
libz-sys and openssl-src. The Rust binding versions are git2 0.21.0 and
libgit2-sys 0.18.8.
The native code licenses cover libgit2 1.9.7, libssh2, OpenSSL 3.6.3 and zlib.
See Cargo.lock for the fixed versions of the build packages.
